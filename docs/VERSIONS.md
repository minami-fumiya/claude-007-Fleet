# バージョン履歴 (アルファ版)

オープンベータまでは要望を追加しながら細かく刻むため、**`0.0.x-alpha`** で管理する。
「くくり」(末尾の番号) は **遊べる内容がまとまって変わった単位** で 1 つずつ上げ、スプリント番号とは一致させない。

- `0.0.x-alpha` … 新しいくくりの完成ごとに x を 1 つ上げる (`0.0.9` の次は `0.0.10`)
- くくりの中の不具合修正だけを出す場合は `0.0.x-alpha.1`, `.2` … を付ける
- **`0.1.0-beta` = オープンベータ** (目安は下の「オープンベータの条件」)、`1.0.0` = 正式公開

> ROADMAP / 各スプリント文書に出てくる「v1.0 候補」「v2.0 候補」は旧来の呼び方。今後はこの表の番号を正とする。

## 0.0.1-alpha — 基盤 (Sprint 0〜2)
- Phaser 3 + TypeScript + Vite の環境、Vercel 公開、CI (型チェック・テスト・ビルド)
- 型定義とシーン構成 (起動 → 読み込み → メニュー → 戦闘)
- 大和 1 隻を操作して戦える。砲撃のダメージ計算 (`CombatSystem`)、武器と装填 (`WeaponSystem`)
- 基本の敵 AI、HP バーと HUD、勝敗判定

## 0.0.2-alpha — 日本艦隊と編成 (Sprint 3)
- 日本海軍 5 隻 (大和・武蔵・高雄・吹雪・翔鶴) と武器データ
- 出撃前の艦隊編成画面 (Fleet Builder)
- 陣形 3 種 (単縦陣・複縦陣・輪形陣) と護衛艦の AI

## 0.0.3-alpha — スマホ対応と UI 刷新 (#10〜#12)

- スマホ対応: 画面サイズへの自動調整、仮想ジョイスティック、タップで射撃
- UI の全面刷新、日本語フォント、縦画面レイアウト、タッチ操作と AUTO 戦闘、戦闘海域の拡大

## 0.0.4-alpha — 多国籍海軍・航空戦・艦長とカスタマイズ (Sprint 4〜5)
- 米海軍・ドイツ海軍・英海軍が加わり 4 か国に
- 国ごとに戦い方の違う AI (AI v2)

- **カスタマイズ**: 艦ごとの強化部品 (射撃指揮装置・強装薬・魚雷改良・追加装甲・機関強化・応急修理班 など 8 種)

## 0.0.5-alpha — 鎮守府・資源・研究・演出 (Sprint 6〜7)

## 0.0.8-alpha — 遊びやすさの調整 (Sprint 13, PR #62)
プレイテスト第 2 弾 (#32) の実装順 0〜1。
- セーブデータの段階的な移行の仕組み (#60) — 以降の版でセーブに項目を足しても、古いセーブの艦・艦長・資源が消えない
- 敵が旗艦ばかり狙わず、攻撃を艦隊に分散する (#34)。ドイツは損傷艦に集中する性格を維持
- 鋼材不足の解消 (#35): 鋼材の自然回復 +5/分、修理の鋼材を減らし、戦闘報酬の鋼材を増やす
- 設定で移動スティックを非表示にできる (#46)

## 0.0.9-alpha — 編成画面と陣形 (実装順 2)
- スマホの編成画面 (#33): 縦画面は出撃枠が増えても 1 列。カードに艦種・耐久・装甲・速力・熟練度・主兵装。「詳細」で兵装・艦載機・状態・艦長をまとめて表示。艦一覧の艦種フィルタと並べ替え。編成プリセット 3 枠 (陣形・艦長も保存)
- 軽巡・重巡の区別 (#37): 編成・艦一覧・造船所・作戦の報酬表示で 重巡 / 軽巡 などの艦種を表示。軽巡は出撃・建造コストが安く、重巡は「重巡洋艦建造」の研究が必要 (以前から巡洋艦を建造できたセーブは両方建造可のまま)。敵 AI は重巡を軽巡より優先して狙う
- 陣形 6 種 (#59): 梯形陣・単横陣・警戒陣を追加し、全陣形に効果 (砲火力・対空・対潜・回避・旗艦の保護) を付与。新しい 3 つは階級で解放

## バージョンの付け方
- くくりが `develop` → `main` にマージされたら、そのコミットに `v0.0.x-alpha` のタグを付け、`package.json` の `version` を合わせる
- 過去のくくりにタグを付ける場合の対象コミット:
  0.0.1 = `0573889` / 0.0.2 = `114453a` / 0.0.3 = `ecc1019` / 0.0.4〜0.0.7 = `9024103` (4 つのくくりが 1 つの PR #14 にまとまっているため同じコミット)
