# バージョン履歴 (アルファ版)

オープンベータまでは要望を追加しながら細かく刻むため、**`0.0.x-alpha`** で管理する。
「くくり」(末尾の番号) は **遊べる内容がまとまって変わった単位** で 1 つずつ上げ、スプリント番号とは一致させない。

- `0.0.x-alpha` … 新しいくくりの完成ごとに x を 1 つ上げる (`0.0.9` の次は `0.0.10`)
- くくりの中の不具合修正だけを出す場合は `0.0.x-alpha.1`, `.2` … を付ける
- **`0.1.0-beta` = オープンベータ** (目安は下の「オープンベータの条件」)、`1.0.0` = 正式公開

> ROADMAP / 各スプリント文書に出てくる「v1.0 候補」「v2.0 候補」は旧来の呼び方。今後はこの表の番号を正とする。

## 0.0.11-alpha — 不具合と操作性 (#76〜#80 #98 #101)
- 同じ艦の重複なし (#76): 自艦隊は同じ艦を 2 枠に入れられない。敵 (演習・作戦・史実) も同じ艦が並ばない (足りなければ同じ艦種の別の艦、それも無ければ隻数を減らす)
- 編成画面 (#77): 枠をタップすると艦の選択シート (艦種の絞り込み・並べ替え付き、編成中の艦は選べない)。縦画面の常設の艦一覧を無くし、艦の入れ替えと出撃が 1 画面で済む。陣形・交戦相手・戦闘の種類・天候・時間・敵の数は折りたたみ式のラジオボタン (開くのは 1 つだけ)。鎮守府へ戻るなど、どの方法で画面を離れても編成は国ごとに保持。鎮守府のメニューに「編成」
- 演習の設定 (#78): 敵の数は 同数 / 1〜10 隻。交戦相手の国・戦闘の種類・天候・時間に「ランダム」、初期値はすべてランダム (出撃のたびに抽選)
- 一時停止 (#79): 戦闘中の「一時停止」ボタン (PC は P / Esc)。再開・撤退を選べる。タブを切り替えると自動で一時停止。戦闘時間・装填・損傷の時間も止まる
- 護衛艦の迷走 (#80): 後方の護衛が旗艦の旋回のたびに右往左往せず、隊形の向きをゆっくり追って自分の位置を保つ。対潜攻撃中は艦名の横に〈対潜攻撃〉と表示
- 偵察機の触接 (#98): 敵を見つけた偵察機はその敵の上空を旋回して見え続けるようにする (最大 90 秒、主力艦を優先)。見失った敵は最後に見えた位置に 30 秒間印を残す
- 画面の自動テスト (#101): Playwright で全メニュー画面を縦横両方で開き、エラーと画面外へのはみ出しを確認、出撃〜一時停止まで通す。CI に「E2E」ジョブを追加 (`npm run test:e2e`)

- バックアップから復元 (#157): 一覧をシートで開き、画面からはみ出さないように。2 回タップで復元 (復元前のセーブも退避)
- 艦長の推奨艦と自動配属 (#164): 艦長画面に適性 S の保有艦を 3 隻まで表示。編成画面の「艦長を自動配属」で、旗艦から順に適性とレベルの合う艦長を割り当て。艦長をタップで切り替える順も適性の高い順に
- 重なりの自動検査 (#163): E2E で全画面の文字どうしの重なりを縦横とも検査。艦・艦長・攻略済み海域の多いセーブでも検査
- セーブの形式は変更なし (v11)

## バージョンの付け方
- **マージの手順**: α 版の間は、CI が通った PR を `develop` にマージしたら、続けて `develop` → `main` もまとめてマージして公開する。β 版 (0.1.0-beta) からは `develop` で確認してから `main` へ、と段階を踏む

- 過去のくくりにタグを付ける場合の対象コミット:
