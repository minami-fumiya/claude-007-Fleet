# バージョン履歴 (アルファ版)

正式公開前のため、全体を **アルファ版 `0.x.0-alpha`** として管理する。
「くくり」(マイナー番号) は **遊べる内容がまとまって変わった単位** で切り、スプリント番号とは一致させない。

- `0.x.0-alpha` … 新しいくくり (機能のまとまり) の完成
- `0.x.y-alpha` … そのくくりの中の不具合修正・調整
- `1.0.0` は「ベータ / 一般公開」に移る時に付ける (目安は下の「1.0 の条件」)

> ROADMAP / 各スプリント文書に出てくる「v1.0 候補」「v2.0 候補」は旧来の呼び方。今後はこの表の番号を正とする。

## 0.1.0-alpha — 基盤 (Sprint 0〜2)
- Phaser 3 + TypeScript + Vite の環境、Vercel 公開、CI (型チェック・テスト・ビルド)
- 型定義とシーン構成 (起動 → 読み込み → メニュー → 戦闘)
- 大和 1 隻を操作して戦える。砲撃のダメージ計算 (`CombatSystem`)、武器と装填 (`WeaponSystem`)
- 基本の敵 AI、HP バーと HUD、勝敗判定

## 0.2.0-alpha — 日本艦隊と編成 (Sprint 3)
- 日本海軍 5 隻 (大和・武蔵・高雄・吹雪・翔鶴) と武器データ
- 出撃前の艦隊編成画面 (Fleet Builder)
- 陣形 3 種 (単縦陣・複縦陣・輪形陣) と護衛艦の AI

## 0.3.0-alpha — スマホ対応と UI 刷新 (#10〜#12)
- 不具合修正 (#5〜#9: 起動時のクラッシュ、艦の画像、艦名、HP バーの位置)
- スマホ対応: 画面サイズへの自動調整、仮想ジョイスティック、タップで射撃
- UI の全面刷新、日本語フォント、縦画面レイアウト、タッチ操作と AUTO 戦闘、戦闘海域の拡大

## 0.4.0-alpha — 多国籍海軍・航空戦・艦長とカスタマイズ (Sprint 4〜5)
- 米海軍・ドイツ海軍・英海軍が加わり 4 か国に
- 国ごとに戦い方の違う AI (AI v2)
- 潜水艦戦: 潜航・魚雷・ソナー・爆雷
- 空母の艦載機 (攻撃隊・直掩機・対空砲火)、偵察と索敵、視界外の敵が見えない FogOfWar
- 艦長 (経験値・レベル・スキル)
- **カスタマイズ**: 艦ごとの強化部品 (射撃指揮装置・強装薬・魚雷改良・追加装甲・機関強化・応急修理班 など 8 種)

## 0.5.0-alpha — 鎮守府・資源・研究・演出 (Sprint 6〜7)
- 鎮守府 (母港) 画面
- 4 資源 (燃料・弾薬・鋼材・ボーキサイト)、出撃にかかる資源
- 損傷の持ち越しと入渠 (修理ドック 2 つ・高速修理)
- 工廠の研究ツリー (全艦への強化と装備の解放)
- 効果音と BGM (WebAudio で生成)、爆発などの演出、天候 (晴天・曇天・霧・嵐)、夜戦
- 損傷表現とバランス調整

## 0.6.0-alpha — 作戦・史実シナリオ・育成・図鑑 (Sprint 8〜11)

## バージョンの付け方
- くくりが `develop` → `main` にマージされたら、そのコミットに `v0.x.0-alpha` のタグを付け、`package.json` の `version` を合わせる
- 過去のくくりにタグを付ける場合の対象コミット:
  0.1 = `0573889` / 0.2 = `114453a` / 0.3 = `ecc1019` / 0.4〜0.7 = `9024103` (4 つのくくりが 1 つの PR #14 にまとまっているため同じコミット)
