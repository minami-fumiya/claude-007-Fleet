# 黄色 (gold) のボタン (#269)

黄色のボタンは「今押すと、その操作ができる」ものだけに使う。押してもできない (資源・熟練・枠が足りない) ボタンは通常の色 (secondary) にする。説明の画面を開くだけのボタンは押せたままでよいが、黄色にはしない。

- 判定は `actionVariant(ready)` (`src/ui/components/UIKit.ts`) で行う。
- 状態が変わるボタンは `refresh` のたびに `setVariant` を呼び直す。

## 0.0.36 の点検結果

| 画面 | ボタン | 0.0.35 まで | 0.0.36 |
|---|---|---|---|
| 母港 | 作戦・編成・研究 | 常に黄色 | 任務・掃討・教本・工事など、待っているものがある画面だけ黄色 |
| 改装 | 改造 / 方向を選ぶ / 方向を変更 | 常に黄色 | 資源と熟練が足りる時だけ黄色 |
| 改装 | 方向の一覧の「改造」「変更」 | 常に青 | 資源が足りる時だけ黄色 (押せない時は灰) |
| 出撃の編成 | 出撃 | 押せない時も黄色 | 押せる時だけ黄色 |
| 研究 | 分野のタブ | 全部終わると黄色 | 通常の色のまま「完了」と出す |
| 建造・軍港・ショップ・海域・任務 | 建造 / 着工 / 交換 / 出撃 / 受け取る | 条件付き | そのまま (条件付きの黄色) |
| 艦長 | 教本を使う | 教本がある時だけ表示 | そのまま |
