# 記録と艦の個性 (0.0.51: #92 #58 #56 #252 #94 #95 #317)

## 通算の記録 (#92) — `RecordSystem.ts` `ICareerStats`
作戦と演習の戦闘を 0.0.51 から数える (史実は入れない。通算の戦績と同じ扱い)。

| 項目 | 数え方 |
|---|---|
| 航行距離 (海里) | 自分の艦隊の艦の速さ × 時間。`PX_PER_NM = 264` (速力 1 ノット ≒ 4.4 px/s、戦闘の 1 秒 = 海上の 1 分) |
| 主砲・副砲の発射 / 命中 | 艦の砲から撃った弾。航空機の爆弾・魚雷は入れない (`fromShip`) |
| 魚雷の発射 / 命中 | 1 斉射 = 2 本 |
| 爆雷の投下・敵機の撃墜・受けたダメージ | 戦闘ごとの合計 |
| 戦闘時間の合計・最も長い戦闘・最も早い勝利・1 戦の最多撃沈 | |

勲章: 航海章・砲術章・雷撃章・名射手章 (1,000 発以上撃って命中率 25 / 35 / 45%)・一網打尽章・戦闘時間章・称号章。

## 称号 (#92) — `AdmiralTitles.ts`
勲章 1 つにつき称号 1 つ (36 種)。戦績 → 称号で 1 つ選ぶと、鎮守府の階級の前に「称号」が出る。持っていない称号は出ない (`wornTitle`)。

## 艦の固有スキル (#58) — `ShipSkillSystem.ts`
各国の有名な艦 62 隻。自分の艦だけに効く (敵の強さは難しさの曲線のまま)。改二 (改装段階 2) から 1.5 倍。

| 種類 | 効果 |
|---|---|
| 常時 | `IShipModifiers` に合成 (砲撃・速力・対空など、+3〜12%) |
| 幸運 (`luck`) | 被弾を一定の確率で無効にする (6〜12%) |
| 不屈 (`lastStand`) | 耐久 30% 以下で装甲 +6〜10 (戦闘の終わりまで) |

幸運と不屈が働くと艦の上に表示し、任務の累計 `skillProc` に数える (固有スキル章)。

## 艦隊技術 (#56) — `FleetTechSystem.ts`
セーブから計算する (新しい保存項目はない)。国ごと・艦種ごとのポイント: 入手 1、改 +1・改二 +2・改三 +2、練度 100 で +2。
Lv は 5 / 15 / 30 / 50 / 80 ポイント (最大 Lv5)。1 Lv ごとに、戦艦: 砲撃 +1.5%・耐久 +1%、巡洋艦: 装填 −1.5%・対空 +2%、
駆逐艦: 雷撃 +2%・回避 +0.5%、空母: 航空 +2%・再出撃 −1.5%、潜水艦: 雷撃 +2%・速力 +1%。図鑑の艦艇タブの「艦隊技術 ›」。

## 艦長 (#252) — `captains.json`, `CaptainSystem.ts`
各国 50 人 (実在の指揮官を各国 20 人追加)。特性は 3 → 13 種 (水雷の名手・航空戦の名手・大物食い・撃沈王・歴戦の艦長・
常勝の艦長・旗艦の重み・無傷の名手・ダメコンの鬼・夜の支配者)。艦長の記録に、出撃・勝利・旗艦での勝利・無傷の勝利・
魚雷 / 艦載機での撃沈・戦艦か空母の撃沈を足した (旧セーブは 0 から)。止めを刺した武器は `BaseShip.lastHitKind`。

## 表示 (#94 #95)
- テーマ: `theme.ts` の `applyTheme` を起動の最初 (`themeBoot.ts`) に呼ぶ。ライトは白地に濃い文字 (文字と白のコントラスト 4.5:1 以上をテストで確認)。切り替えると読み込み直す。
- ふりがな: `RubySystem.ts` と `ruby.json`。Phaser の `Text.setText` を差し替え、語の後ろに〈よみ〉を付ける (1 つの文で最初の 1 回だけ、ボタンの文字には付けない)。
- 色の記号: 戦力比に「▲ 有利・◆ 互角・▼ 不利」 (`strengthMark`、色と同じ区切り)。
- 縦横: スマホは持ち方で縦・横を決める (`resolveOrientation` の `wide`)。設定で縦固定・横固定。向きが変わると、開いていた画面のまま読み込み直す (`OrientationWatch.ts`、戦闘中は戦闘の後)。横持ちのスマホは文字を 1.15 倍。
