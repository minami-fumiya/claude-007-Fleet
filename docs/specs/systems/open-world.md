# 本当のオープンワールド — 計画 (#65 の続き、#445)

0.0.65〜0.0.67 の「外洋」は、オープンワールドと呼ぶには足りない。この文書は、今の要素を残したまま、続いた一つの世界の海を自由に走れる形に作り直す計画。

**2026-11-07 ユーザー確定。** 決めたことの一覧は末尾の「決めたこと」。

## 今の外洋 (0.0.67) は何が足りないか

| | 今の外洋 | 本当のオープンワールド |
|---|---|---|
| 移動 | 海図の印をタップすると、その場所へ瞬間移動する | 艦隊が海の上を時間をかけて進み、途中で何かに出会う |
| 世界 | 国ごとに 1000 × 1000 の点の地図。陸も海流もない | 陸地・島・海峡・浅瀬・海流のある、続いた一つの世界の海 |
| 敵 | 1 時間ごとに決まった場所へ置かれ、動かない | 航路を巡回し、見つけると追い、負けそうなら逃げる |
| 出会い | 自分から印を選んだ時だけ戦う | 視界に入った敵と、その場で戦う |
| 時間 | 1 時間ごとに配置が入れ替わるだけ | 世界の時計が進み、昼夜・天候・敵の動きが続いて変わる |
| 補給 | 距離から計算した数字が減る | 走った分だけ燃料が減り、港や補給艦で積む |
| 艦隊 | 1 艦隊だけ | 艦隊を分け、任務を与え、いつでも指揮を移せる |
| 領域 | 危険度の輪で週に 3 勝すると制海権 | 海の地方ごとの制海権と、空の地方ごとの制空権 |
| 戦闘 | 毎回同じ「外洋」の海図 | 出会った場所の島・天候・時刻のまま戦う |

## 世界は 1 つ、遊ぶ国は選ぶ (2026-11-06 ユーザー判断)

- 調べたこと: 作戦の 9 戦域 (南太平洋・北大西洋・地中海・バルト海・黒海・北太平洋・南大西洋・インド洋・北極海) は、もともと国で分かれていない。どの国で遊ぶかで、同じ海域の敵 (`opponents`) が入れ替わるだけ。国ごとに分かれているのは「遊ぶ国の進行」(艦・資源・階級・研究・艦長・国家方針・基地など約 60 項目、`INationProgress`)。
- そこで、**世界の地図は 1 枚** にし、9 戦域をその上の実際の場所に置く。各国の軍港は作戦の本拠地 (`bases.json` の最初の軍港) の場所に置く (横須賀・ノーフォーク・ポーツマス・キール・トゥーロン・ラ・スペツィア・クロンシュタット)。本拠地の戦域と、軍港の区画の戦域がそろう。どの国で遊んでも同じ世界で、出発する軍港と、敵と味方が変わる。
- **遊ぶ国は今のまま選ぶ。** 進行は国ごとのまま (保存の大きな作り直しをせず、国ごとの個性と遊び直しを残す)。艦隊も今のまま 1 か国の艦で組む。
- 旗艦のまわりの区画だけ読み込む作りなので、世界が広くても重さは変わらない。「7 か国の海をつなぐ」段階は要らない。

## 残す要素と、新しい世界での姿

今の仕組みと勲章は、どれも名前と意味を保ったまま新しい世界に移す。

## 作り

### 戦闘画面をそのまま広げる (2026-11-05 ユーザー判断)
- 航海の画面を別に作らず、**今の戦闘画面の海を広げて、そのまま航海する**。艦の操作・射撃・AUTO・霧・HUD は戦闘と同じで、敵に出会えばその場で戦闘になる。画面は切り替わらない。
- **ミニマップと海図は戦闘画面と分ける。** 戦闘画面の隅のミニマップは「近くの様子」(周り 3 × 3 区画)、海図は別の画面 (重ねて開く) で「世界全体」(航路を引く・場所を見る・艦隊の一覧)。
- 戦闘画面の作りは、3D 化 (#96) と UI の作り直し (#397) でもそのまま使える。

### 世界のデータ
- **区画:** 今の戦闘の海 (3200 × 3200 px) を 1 区画とする。世界は 1 枚で 72 × 40 区画 (経度 5°・緯度 3.25°、北緯 76° 〜 南緯 54°、0.0.68)。各区画が陸・海・浅瀬・海流・危険度を持つ。
- **海の地方・空の地方:** 区画のまとまり。1 つの戦域を 3〜5 の地方に分ける。制海権 (C1)・制空権 (C2)・哨戒の範囲の単位。
- **陸と港:** 区画の上に島と海岸線を置く。港・油田・鉱山・要塞・軍港は海岸線の上の点。
- **住人:** 敵艦隊・船団・友軍の巡回・自分の分けた艦隊は「航路」と「状態 (巡回・追跡・逃走・入港・帰投・待機)」を持つ。純粋な仕組み (`WorldSim`) で 1 歩ずつ動かし、Vitest で確かめる。

### 時間
- 世界の時計は、**本物の 5 分 = 世界の 1 時間** (本物の 2 時間で世界の 1 日) で進める (2026-11-05 ユーザー判断)。昼夜と天候の前線が動く。航行の早送り (×4・×8) の間は、時計も同じ倍率で進む。
- 遊んでいない間の世界は、開いた時に経過時間の分だけ決まった手順で進める (上限は世界の 24 時間)。乱数を固定した種で回すので、同じ時刻には同じ世界になる。保存には変わった部分だけを残す。

### 視界と出会い
- 艦隊の視界 (艦種・レーダー・偵察機・天候・夜・制空権) の内側だけ敵が見える。見えない敵は前に見た位置だけ薄く残す。
- 敵の視界に入ると、敵は自分の強さと比べて「追う」か「逃げる」を決める。
- 出会うと、戦闘画面のままその場で交戦になる。逃げたい時は離れて走る (速い方が逃げ切れる)。

### 複数の艦隊と指揮 (2026-11-06〜07 ユーザー判断)
- **自分で操る艦隊は 1 つ。** ほかの艦隊 (分けた艦隊・遠征・哨戒などの任務の艦隊) は AI が動かす。
- **指揮を移す:** 海図の「艦隊の一覧」から、どの艦隊にも **いつでも** 移れる。見る場所をその艦隊の旗艦に移し、まわりの区画を読み込んで、その時の耐久・位置のまま本物の艦として出す。前の艦隊は命令の続き (なければ待機) をする。
- **画面の外の艦隊は、操っている艦隊と同じ動き方をする。** 世界の時間で普通に動き、敵を見つけると命令に従って AUTO と同じ考えで動く。画面の外の戦いも、時間に合わせて少しずつ進む (軽い計算で耐久が減る)。途中で指揮を移せば、そのまま自分で操れる。
- **画面の外では沈まない。** 大破した艦は自動で帰投する。
- **戦いの途中で別の艦隊へ移った時**、残した艦隊は「撤退」(戦場から離れる) になる。沈まない代わりに、その戦いは負け扱い (案 a、2026-11-07 ユーザー判断)。負けそうな戦いから移るだけで沈む心配をなくす抜け道を防ぐ。

### 重さの目安
- 広い海で同時に動かす住人は 60 まで。画面の外の住人は 1 秒に 10 回だけ動かす。
- `docs/specs/systems/performance.md` の目安 (CPU ×4 で 8 ms 以下) を広い海の戦闘画面にも当てる。

### 保存
- α 版の決まりどおり、新しい項目は既定値付きで読む。今の `world` (航海中の艦隊・制海権・訪れた場所・要塞) は、軍港から始め直す形で読み替える。
- 世界の地図は国で共通、進行 (位置・燃料・探索済みの区画・分けた艦隊・任務) は国ごとに保存する。
- A で増える保存は小さい。住人と複数の艦隊で大きくなる B1 の前に、クラウドセーブ (#116) で保存の作りを整えておく。

## 段階ごとの中身

### A1 続いた海と航海 (0.0.68、公開済み)

**0.0.68 で入れたもの:** 世界の地図 (`scripts/gen-world.ts` → `src/data/world/world.json`、`src/systems/OpenSeaSystem.ts`)、戦闘画面の広い海 (`src/scenes/battle/OpenSeaVoyage.ts`)、海図 (`src/scenes/OpenSeaChartScene.ts`)、外洋の画面の「広い海へ」。早送りは物理の計算を増やさず、艦の速さを上げる形にした。海の区画の数・燃料の距離は `docs/balance/0.0.68.md`。

#### 目標
軍港を出た艦隊を、戦闘画面のまま世界の海へ走らせられる。ミニマップで周りを、海図で世界全体を見る。この版では敵は出さず、今の外洋の画面 (`WorldMapScene`) を残したまま、広い海の航海を「試しの航海」として軍港から出す。

#### 1. 世界の地図と区画
- 区画ごとのデータ (`src/data/world/world.json`):
  - `kind`: 外洋 / 沿岸 / 群島 / 陸 (陸の区画は通れない)
  - `islands` `shoals` `currents`: 今の戦闘の地図 (`src/data/maps/*.json`) と同じ形 (区画の中の 0〜1 の座標)
  - `danger`: 1〜10。各国の軍港からの距離で決める (国ごとに違うので、区画には「場所」だけ持たせ、危険度は遊ぶ国の軍港から計算する)
  - `region`: 海の地方 (戦域とその中の地方)
  - 軍港・港・油田・鉱山・要塞・作戦海域の範囲は、区画と区画の中の位置で置く
- 地図はスクリプト (`scripts/gen-world.ts`) で作る: 世界地図を簡単にした陸の形 (区画の数だけの文字の絵) から `kind` を決め、島・浅瀬・海流は今の地図 (archipelago・atoll・strait・open-sea) を種で選んで少しずつ変えて置く。
- **開け方:** 最初は自国の軍港のまわりの戦域だけ海図に出る。ほかの戦域は、今の戦域の解放 (基地の順番、`theaterOrder`) に合わせて開く。
- データ検査: 各国の軍港から全ての港・資源・要塞・作戦海域へ海でつながる、陸に港がない、区画の端で島が切れない、9 戦域が全て地図の上にある。

#### 2. 戦闘画面を広げる (BattleScene の作り直し)
今の BattleScene は「3200 px の海で 1 戦して終わる」作り。広い海でも動くように分ける。
- **海の大きさ:** `WORLD` (今は定数) を戦闘の始めに決める値にする。物理の境界・カメラの境界・AI の境界 (`WORLD_BOUNDS`) をそれに合わせる。普通の戦闘は 3200 のまま。
- **地形の読み込み (`SectorStreamer`、新しい部品):** 旗艦のまわり 3 × 3 区画だけ、島の当たり判定・島と浅瀬の絵・海流を作り、離れた区画のものは消す。旗艦が区画をまたぐたびに入れ替える。今の `resolveMap` `drawMap` を区画ごとに呼ぶ形にする。座標は区画ごとの相対座標で持ち、浮動小数の誤差が大きくならないようにする。

#### 3. 航行と交戦の 2 つの状態
| | 航行 | 交戦 (A2 から) |
|---|---|---|
| いつ | 近くに現れた敵がいない | 敵が現れている |
| 操作 | 戦闘と同じ (スティック・タップ) + 海図で行き先 | 戦闘と同じ |
| 時間 | ×1 (0.0.69 で早送りを外した) | ×1 |
| AUTO | 行き先へ航路をたどる (陸と浅瀬を避ける) | 今の AUTO (戦う) |
| 燃料 | 走った距離で減る | 同じ |
| BGM | 航海の曲 | 戦闘の曲 (今の切り替えを使う) |

#### 4. ミニマップと海図 (分ける)
- **ミニマップ (戦闘画面の隅、今の `Minimap` を広げる):** 旗艦を中心に 3 × 3 区画。島・自艦隊・見えている敵・港などの印。世界全体は描かない。
- **海図 (別の画面、戦闘画面の上に重ねて開く):** 世界全体。探索済みの区画だけ色が付き、まだの区画は霧。軍港・港・資源・要塞・作戦海域・見つけた敵艦隊の印。拡大・縮小できる。タップで行き先を置くと、航路 (区画の上の A* 探索、陸と浅瀬を避ける) と、行き先と帰りに要る燃料が出る。閉じると戦闘画面に戻り、AUTO なら航路をたどる。
- 海図を開いている間、時間は止まる。

#### 5. 燃料
- 今の「補給 100」を燃料タンクとして残す。減り方は走った距離 (今の航行距離の記録 `sailedPx` と同じ数え方) で、1 区画で約 3。
- 海図で、今いる所から軍港・最寄りの港までの燃料を出す。帰りの分を切ったら警告し、AUTO なら最寄りの港へ向ける。

#### 6. 視界と探索
- 今の霧 (`FogOfWar`) は画面の大きさで描いているので、広い海でもそのまま使える。
- 探索済みの区画 (1 区画 1 ビット) を国ごとに保存し、海図の霧を晴らす。

#### 7. 重さ (CPU ×4 で 1 フレーム 8 ms 以下を保つ)
- 当たり判定のある島は 3 × 3 区画分だけ。早送り ×8 の時は、AI と霧の計算を 1/2 の頻度に落とす。
- `npm run perf` に「広い海を ×8 で 2 分走る」測り方を足す。

#### 8. 作る順番 (A1 の中)
1. `WORLD` を変えられるようにし、`SectorStreamer` で 2 × 2 区画の試しの海を走れるようにする。
2. 世界の地図のデータと生成スクリプト、データ検査。
3. 海図の画面と航路・燃料・早送り。
4. 勲章 (航海の距離・探索した区画)・ヘルプ・E2E・バランス確認。

### A2 地図の作り直しと停泊 (2026-11-08 ユーザー判断)
A2 に入る前に、0.0.68 の地図と速さを次のように変える。A2 は 2 版 (0.0.69 = A2a、0.0.70 = A2b) に分ける。

**細かい地図**

#### 1. 敵の出し入れと、その場での交戦の精算
- **現れる・消える:** 海の敵艦隊は、普段はデータ (位置・編成) だけで、旗艦から 1.5 区画 (約 4800 px) 以内に入ると本物の艦 (`BaseShip`) として現れる。今の `spawnEnemyGroup` (演習の 2 艦隊目に使っている) を広げて使う。視界の外まで離れ、戦っていなければ、データに戻して消す。現れている敵は 30 隻まで。
- **交戦の精算:** 今は戦闘の終わりの処理 (`triggerGameOver` の中の報酬・損傷・熟練度・任務・勲章) が画面の終わりと一体になっている。これを `settleEngagement()` として取り出し、現れた敵艦隊が全て沈むか逃げ切ったところで呼ぶ。画面は変えず、結果は上の帯 (と戦闘ログ) で知らせる。旗艦が沈んだ時だけ今の結果画面へ進み、艦隊は帰港する。

#### 2. 作戦海域 (作戦を海の上の範囲に)
- 作戦の海域は、区画の上の 2 × 2 区画ほどの範囲。戦域ごとにまとめて置き、近づくと「作戦海域」の印と、目標・推奨の階級と総戦力が出る。
- **今の出撃の道筋 (途中の場所 1 つとボス) を、範囲の中に実際に置く:**
  - 前衛 (敵の軽い艦から最大 3 隻) は入口のあたりを巡回する。夜や霧に紛れて避けて通ることもできる (避ければ前衛の報酬はない)。
  - 補給の場所は浮いている物資や補給船。通ると資源が入る。
  - 渦潮は渦の範囲。通ると燃料が減り、速力も落ちる。避けて通れる。
  - ボス (敵の主力) は奥にいる。沈めたら攻略で、評価 (S〜D)・報酬艦・初回の報酬・攻略の記録は今のまま数える。
  - 戦域の最初の海域と、敵の少ない海域は、今と同じくボスだけ。
- 損傷はそのまま持ち越し。範囲から出れば撤退 (沈めた前衛は、その 1 時間は戻らない)。
- **目標 7 種の海の上の形:**

| 目標 | 外洋での形 |
|---|---|
| 殲滅・撃沈目標 | ボスの艦隊を沈める |
| 船団護衛 | 範囲の中で船団を入口から出口まで送る |
| 対地攻撃 | 範囲の中の島の陣地を壊す (上陸支援・機雷原・防潜網も今の仕組みのまま置く) |
| 突破 | 範囲の奥のゾーンに旗艦を入れる |
| 遅滞 | ゾーンを時間まで守る |
| 脱出阻止 | 範囲の出口へ逃げる敵を追って沈める |

- **近道の一覧 (作戦の画面を残す、2026-11-06 ユーザー判断):** 今の作戦の画面で海域を選ぶと、一番近く停泊している艦隊が自動航行でその作戦海域の入口まで走る (そこまでの燃料は使う、2026-11-08 で早送りをやめて停泊に)。
- 出撃コストは燃料と補給に置き換える。出撃の中断・再開は、航海の保存にまとめる。

#### 3. 訓練海域と演習場 (2026-11-06 ユーザー判断)
- 訓練海域は軍港のすぐ近くの安全な海。今の訓練海域の敵がそこに出る。
- 軍港の近くに「演習場」の場所を置く。入ると、今の演習の設定 (敵の数・国・難しさ) を選んで、その場で始まる。

#### 4. 港・資源・要塞 (海の上の本物の場所)
- **港:** 港の円に入ると入港の帯が出る (補給 100・応急修理 60%・帰港)。他国の港は同盟国のものだけ使える。軍港の円では「帰港」だけ。
- **油田・鉱山:** 円の中を通ると資源 (今と同じ量、1 時間に 1 回)。
- **船団の航路:** A2 では、航路の起点に船団 (輸送船 2〜3 隻と護衛) が止まっている。沈めると資源 (B1 で動き出す)。
- **要塞:** 要塞の島に近づくと、陣地と守備艦隊が現れ、その場で対地攻撃になる。

#### 5. 艦隊の分離 (2026-11-06 ユーザー判断)
- 戦闘画面で艦を選び「分離」を押すと、その艦だけの別の艦隊になり、AI が動かす。
- 命令:

| 命令 | 動き |
|---|---|
| 帰投 | 自分で最寄りの港 (または軍港) へ走って帰り、着いたら入渠に入る |
| 待機 | その場か、近くの島の陰 (泊地) で止まって待つ |
| 合流 | 近くの艦隊へ走って行って合流する |

- 今の大破 (耐久 25% 以下) で艦隊から抜ける決まりは、「分離して帰投か待機を選ぶ」に置き換える。
- 今の外洋の画面 (`WorldMapScene`) はこの版で外す。

#### 6. 保存

#### 7. テスト
- 純粋な仕組み (Vitest): `WorldGrid` (区画の読み出し・陸の判定・危険度)、`WorldRoute` (航路と燃料)、`SectorWindow` (どの区画を読み込むか)、敵の出し入れの判定、交戦の精算 (報酬・損傷・任務)、作戦海域の中の配置、艦隊の分離。

- 模擬: 作戦海域の戦いを各戦域で流し、今の作戦と勝率が大きく変わらないことを見る。

### B1 動く世界 (0.0.72)
**世界の時計**
- 本物の 5 分 = 世界の 1 時間 (世界の 1 日 = 本物の 2 時間)。昼夜は世界の時刻で決まり、戦闘の時刻 (昼・夜) もそれに従う。1 回の遊び (30 分〜1 時間) で、昼から夕方・夜へ移るくらいの速さ。
- 天候は前線 (雨・霧・嵐の帯) が区画の上を流れる。嵐の区画は速力が落ち、視界が狭い。

**住人 (`WorldSim`)**
- 敵艦隊・船団・友軍の巡回は「航路」と「状態」を持つ。状態は 巡回 → 発見 → 追跡 / 逃走 → 見失う → 巡回。
- 発見した時に、自分と相手の総戦力 (今の `fleetPower`) を比べて、追うか逃げるかを決める。
- 船団は港と港の間を往来する。襲うと資源が入り、護衛が付いていることがある。
- 友軍の巡回は自国の海を回り、近くの戦闘に加わる (今の「友」と同じ働き)。
- 他国の戦域では、その国の艦隊が住人になる。同盟と敵の関係 (今の戦域の `opponents`) に従い、敵国の艦隊は追って来て、同盟国の艦隊は友軍と同じ働きをする。中立の国の艦隊は、こちらから撃たない限り戦わない。
- 住人は 60 まで。数と配置は世界の時刻と固定した種で決まるので、保存するのは「沈めた」「動きが変わった」ものだけ。

**作戦の動き出し**
- 船団護衛は、船団が港から港へ実際に動き、それを守る形にする。
- 脱出阻止は、逃げる敵艦隊を追って沈める形にする。
- 超兵器の海域は、超兵器が海を巡回するようにし、出会うと戦う。
- イベント・記念日・週替わりの特別海域は、期間中だけ海の上に特別な場所として現れる。

**画面の外の艦隊と指揮を移す** (上の「複数の艦隊と指揮」の通り)
- 画面の外の艦隊は世界の時間で普通に動き、戦いも時間に合わせて進む。沈まず、大破で自動の帰投。
- 海図の艦隊の一覧から、いつでも指揮を移せる。戦いの途中で移ると、残した艦隊は撤退 (負け扱い)。
- **自動の帰投の基準** (HoI4 の「修理の優先度」に近い形): 艦隊ごとに「耐久がこれ以下になったら自動で帰投」を決めておく (なし / 大破 / 中破)。操っている艦隊にも使える。
- 分けた艦隊も敵の巡回に見つかることがある。帰投の航路を安全な海にとるかどうかが判断のしどころになる。

**遊んでいない間**
- 開いた時に、経過した世界の時間だけ `WorldSim` を進める (上限は世界の 24 時間 = 本物の 2 時間分)。操っている艦隊は止まって待つ (勝手に戦わない)。

**勲章・任務**
- 「船団襲撃」「追撃戦」「指揮の切り替え」の勲章。任務に「船団を N 回襲う」。

### B2 遠征と哨戒 (0.0.73)
**遠征 (実際に航路を走る、2026-11-06 ユーザー判断)**
- 遠征の行き先を海の上の場所 (資源の産地・他国の港・輸送の目的地) にする。艦隊は航路を自動で往復し、時間は距離と速力で決まる。海図に遠征の艦隊が動いて見え、いつでも指揮を移せる。
- 途中で会う敵の多さは、通る地方の制海権 (C1 からは本物の値、それまでは危険度) で変わる。護衛を付ける・安全な航路を選ぶ・哨戒で先に敵を見つけておく、といった備えが効く。
- 遠征の艦隊にも自動の帰投の基準を付ける。画面の外では沈まない。
- 今の 21 種は、時間が距離に変わる。報酬は「距離が長い・危ない海ほど多い」にし、1 時間あたりの収入は今の目安 (経済の表) に合わせる。階級で開く決まりと同時に出せる数 (1〜3)、海の遠征 (前進遠征拠点) は残す。

**哨戒**
- 艦隊に「哨戒」の任務を与えて海の地方に置く。その地方を巡回して敵を見つけ、見つけた敵は海図に出る。
- 見つけた敵には、その艦隊が命令に従って動く (追う・知らせるだけ)。いつでも指揮を移して自分で戦える。

**勲章・任務**
- 「遠征の航海距離」「哨戒で発見」の勲章。任務に「哨戒で N 回敵を見つける」。

### C1 制海権 (0.0.74)
HoI4 の「海の優勢」と「任務」に倣う。

**海の地方の制海権**
- 地方ごとに 0〜100%。決め手は、その地方で任務に就いている自国の艦隊の戦力と敵の戦力の比 (艦種で重みを変える。主力艦は強く、潜水艦は弱く)、制空権 (C2 から)、最近の勝ち負け。
- 効き目:

| 制海権 | 効き目 |
|---|---|
| 50% 以上 | 船団が通れる (資源の収入)・要塞を落とせる (上陸)・港で補給できる |
| 低い | 敵の巡回と船団への襲撃が増える・燃料が多く要る |
| 0% に近い | 敵の反攻艦隊の出発点になる |

- 今の作戦の海域ごとの制海権と収入・反攻・防衛戦 (#50) は、この地方ごとの制海権にまとめ直す。作戦海域を攻略すると、その地方の制海権が上がる。

**任務**

| 任務 | 中身 |
|---|---|
| 迎撃 | 港で待ち、哨戒が見つけた敵へ向かって戦う |
| 船団護衛 | 自国の船団の航路を守る (資源の収入が減りにくくなる) |
| 通商破壊 | 敵の船団を襲う (資源が入り、敵の制海権が下がる) |
| 機雷敷設・掃海 | 機雷原を置く・取り除く (今の機雷原の仕組みを使う) |
| 訓練 | 安全な海で練度と熟練度を上げる (燃料を使う) |

**敵の反攻**
- 制海権が 0% に近い地方から、敵の反攻艦隊が実際に航路を通ってやって来る。止めないと地方の制海権を取り返される。

**勲章・任務**
- 「制海権」「反攻の撃退」「通商破壊」「船団護衛」の勲章。

### C2 制空権 (0.0.75)
HoI4 では、空の地方ごとに戦闘機の任務で制空権を取り合い、取った側の偵察と戦闘が有利になる。今のゲームの基地航空隊・陸上機・飛行艇・空母の機種を使う。

**空の地方の制空権**
- 空の地方は海の地方と同じ区切り。その地方へ届く基地航空隊 (基地の飛行場から届く範囲)・その地方にいる空母の戦闘機と、敵の飛行場と空母で、自国と敵の空の力を比べて決める。

**航空の任務**

| 任務 | 中身 |
|---|---|
| 制空 | 戦闘機で制空権を取る |
| 索敵 | 飛行艇・偵察機で敵を見つける (哨戒の空の版) |
| 対艦攻撃 | 見つけた敵艦隊を、戦闘の前に攻撃して弱らせる |
| 港湾攻撃 | 敵の港を攻撃して、敵の艦隊の修理を遅らせる |

**戦闘への効き目**
- 制空権が高い地方で戦うと、敵の空襲が減り、こちらの偵察 (霧の晴れ方) が広くなる。低いと、敵の陸上機が戦闘の途中に空襲に来る。
- 制空権は制海権の計算にも入る (海を取るには空も要る)。

**補給線と前線基地 (#50)**
- 港・前線基地から制海権の高い地方でつながっている範囲は、燃料が減りにくく、港の応急修理の上限が上がる。つながりが切れると、その先の地方の制海権が少しずつ下がる。
- 要塞を落とした島に前線基地を置ける (今の「軍港と基地」の基地の働きを外洋にも)。

**勲章・任務**
- 「制空権」「対艦攻撃」「補給線」の勲章。
