# 本当のオープンワールド — 計画 (#65 の続き)

0.0.65〜0.0.67 の「外洋」は、オープンワールドと呼ぶには足りない。この文書は、今の要素を残したまま、続いた一つの海を自由に走れる世界に作り直す計画。

## 今の外洋 (0.0.67) は何が足りないか

| | 今の外洋 | 本当のオープンワールド |
|---|---|---|
| 移動 | 海図の印をタップすると、その場所へ瞬間移動する | 艦隊が海の上を時間をかけて進み、途中で何かに出会う |
| 世界 | 1000 × 1000 の点の地図。陸も海流もない | 陸地・島・海峡・浅瀬・海流のある、続いた一つの海 |
| 敵 | 1 時間ごとに決まった場所へ置かれ、動かない | 航路を巡回し、見つけると追い、負けそうなら逃げる |
| 出会い | 自分から印を選んだ時だけ戦う | 視界に入った敵と出会う。避ける・追う・逃げるを選べる |
| 時間 | 1 時間ごとに配置が入れ替わるだけ | 世界の時計が進み、昼夜・天候・敵の動きが続いて変わる |
| 補給 | 距離から計算した数字が減る | 走った分だけ燃料が減り、港や補給艦で積む |
| 領域 | 危険度の輪で週に 3 勝すると制海権 | 海を区画に分け、区画ごとに取り合う。敵の反攻も艦隊として来る |
| 戦闘 | 毎回同じ「外洋」の海図 | 出会った場所の島・天候・時刻のまま戦う |

## 残す要素と、新しい世界での姿

今の仕組みと勲章は、どれも名前と意味を保ったまま新しい世界に移す。

| 今の要素 | 新しい世界での姿 |
|---|---|
| 危険度の輪 (1〜10) | 軍港から遠いほど危険度が上がる。輪の線ではなく、海図の濃淡で見せる |
| 敵艦隊 (輪ごとに 1 つ) | 危険度に応じた数の敵艦隊が、巡回航路の上を動き続ける |
| 補給 100・帰りの分 | 燃料タンクとして残す。走ると減り、港・油田・補給艦で積む。帰れなくなる前に警告する |
| 港 (補給と応急修理) | 地図の上の本物の港。入港すると補給と応急修理ができ、艦隊の基点にできる |
| 油田・鉱山・船団の航路 | 油田と鉱山は地図の上の場所。船団は航路を実際に動き、襲うと資源が入る |
| 敵の要塞 | 地図の上の島の要塞。落とすと周りの区画が自国のものになる |
| 制海権 | 区画ごとの制海権。区画の中で勝つほど強まり、敵の反攻で揺らぐ (#50 の制海権・反攻と合わせる) |
| 友軍の巡回艦隊 | 自国の区画を実際に巡回する。近くで戦うと加わる |
| 史実の海戦 | 史実の日に、その海戦の艦隊が史実の海域に現れる (#50 の史実の年表と合わせる) |
| 国ごとの海図 | 7 か国の海を一つの世界につなぐ。最初は自国の海だけが見え、進むと他国の海も開く |
| 外洋の報酬・勲章 | そのまま残す (外洋航海章・遠洋章・寄港章・資源輸送章・要塞攻略章・制海章・友軍連携章・史実再現章) |

## 作り

### 戦闘画面をそのまま広げる (2026-11-05 ユーザー判断)
- 航海の画面を別に作らず、**今の戦闘画面の海を広げて、そのまま航海する**。艦の操作・射撃・AUTO・霧・HUD は戦闘と同じで、敵に出会えばその場で戦闘になる。画面は切り替わらない。
- **ミニマップと海図は戦闘画面と分ける。** 戦闘画面の隅のミニマップは「近くの様子」(周り 3 × 3 区画)、海図は別の画面 (重ねて開く) で「海全体」(航路を引く・場所を見る)。
- 戦闘画面の作りは、3D 化 (#96) と UI の作り直し (#397) でもそのまま使える。

### 世界のデータ
- **地図:** 区画 (段階 A は 16 × 16、段階 D で広げる) に分け、各区画が陸・海・浅瀬・海流・危険度・持ち主を持つ。国の海は区画のまとまりで表す。
- **陸と港:** 区画の上に島と海岸線を置く。港・油田・鉱山・要塞は海岸線の上の点にする。
- **住人:** 敵艦隊・船団・友軍の巡回は「航路」と「状態 (巡回・追跡・逃走・入港)」を持つ。純粋な仕組み (`WorldSim`) で 1 歩ずつ動かし、Vitest で確かめる。

### 時間
- 世界の時計は、本物の 1 分 = 世界の 1 時間ほどで進める。昼夜と天候の前線が動く。
- 遊んでいない間の世界は、開いた時に経過時間の分だけ決まった手順で進める。乱数を固定した種で回すので、同じ時刻には同じ世界になる。保存には変わった部分だけを残す。

### 視界と出会い
- 艦隊の視界 (艦種・レーダー・偵察機・天候・夜) の内側だけ敵が見える。見えない敵は前に見た位置だけ薄く残す。
- 敵の視界に入ると、敵は自分の強さと比べて「追う」か「逃げる」を決める。
- 出会うと、戦闘画面のままその場で交戦になる。逃げたい時は離れて走る (速い方が逃げ切れる)。

### 重さの目安
- 広い海で同時に動かす住人は 60 まで。画面の外の住人は 1 秒に 10 回だけ動かす。
- `docs/specs/systems/performance.md` の目安 (CPU ×4 で 8 ms 以下) を広い海の戦闘画面にも当てる。

### 保存
- α 版の決まりどおり、新しい項目は既定値付きで読む。今の `world` (航海中の艦隊・制海権・訪れた場所) は新しい世界の同じ意味の項目に読み替え、航海中の艦隊は最寄りの港から始める。
- 世界の状態は大きくなるので、先にクラウドセーブ (#116) で保存の作りを整えておく。

## 段階ごとの中身

### 段階 A 続いた海と自由航海 (詳細)

#### 目標
軍港を出た艦隊を、戦闘画面のまま自国の海の端まで走らせられる。出会った敵とはその場で戦い、勝っても負けても画面は変わらず、航海が続く (旗艦が沈めば帰港)。ミニマップで周りを、海図で海全体を見る。

#### 1. 海の大きさと区画
- 今の戦闘の海 (3200 × 3200 px) を **1 区画** とし、国の海を **16 × 16 区画** (51,200 px 四方) にする。64 × 64 は重さとデータの量が大きいので、段階 A は 16 × 16 で始め、段階 D で国の海をつないで広げる。
- 区画ごとのデータ (`src/data/world/<国>.json`):
  - `kind`: 外洋 / 沿岸 / 群島 / 陸 (陸の区画は通れない)
  - `islands` `shoals` `currents`: 今の戦闘の地図 (`src/data/maps/*.json`) と同じ形 (区画の中の 0〜1 の座標)
  - `danger`: 軍港からの距離で 1〜10 (今の危険度の輪と同じ考え)
  - 港・油田・鉱山・船団の航路の起点・要塞は、区画と区画の中の位置で置く
- 地図はスクリプト (`scripts/gen-world.ts`) で作る: 国ごとのおおまかな陸の形 (16 × 16 の文字の絵) から `kind` を決め、島・浅瀬・海流は今の地図 (archipelago・atoll・strait・open-sea) を種で選んで少しずつ変えて置く。
- データ検査: 軍港から全ての港・資源・要塞へ海でつながる、陸に港がない、区画の端で島が切れない。

#### 2. 戦闘画面を広げる (BattleScene の作り直し)
今の BattleScene は「3200 px の海で 1 戦して終わる」作り。次の 4 つを分けて、広い海でも動くようにする。
- **海の大きさ:** `WORLD` (今は定数) を戦闘の始めに決める値にする。物理の境界・カメラの境界・AI の境界 (`WORLD_BOUNDS`) をそれに合わせる。普通の戦闘は 3200 のまま。
- **地形の読み込み (`SectorStreamer`、新しい部品):** 旗艦のまわり 3 × 3 区画だけ、島の当たり判定・島と浅瀬の絵・海流を作り、離れた区画のものは消す。旗艦が区画をまたぐたびに入れ替える。今の `resolveMap` `drawMap` を区画ごとに呼ぶ形にする。
- **敵の出し入れ (現れる・消える):** 海の敵艦隊は、普段はデータ (位置・編成) だけで、旗艦から 1.5 区画 (約 4800 px) 以内に入ると本物の艦 (`BaseShip`) として現れる。今の `spawnEnemyGroup` (演習の 2 艦隊目に使っている) を広げて使う。視界の外まで離れ、戦っていなければ、データに戻して消す。
- **戦闘の区切り (交戦の精算):** 今は戦闘の終わりの処理 (`triggerGameOver` の中の報酬・損傷・熟練度・任務・勲章) が画面の終わりと一体になっている。これを `settleEngagement()` として取り出し、現れた敵艦隊が全て沈むか逃げ切ったところで呼ぶ。画面は変えず、結果は上の帯 (と戦闘ログ) で知らせる。旗艦が沈んだ時だけ今の結果画面へ進み、艦隊は帰港する。

#### 3. 航行と交戦の 2 つの状態
| | 航行 | 交戦 |
|---|---|---|
| いつ | 近くに現れた敵がいない | 敵が現れている |
| 操作 | 戦闘と同じ (スティック・タップ) + 海図で行き先 | 戦闘と同じ |
| 時間 | 早送り ×1 / ×4 / ×8 を選べる | ×1 に戻る (敵が現れた瞬間に戻し、知らせる) |
| AUTO | 行き先へ航路をたどる (陸と浅瀬を避ける) | 今の AUTO (戦う) |
| 燃料 | 走った距離で減る | 同じ |
| BGM | 航海の曲 | 戦闘の曲 (今の切り替えを使う) |

#### 4. ミニマップと海図 (分ける)
- **ミニマップ (戦闘画面の隅、今の `Minimap` を広げる):** 旗艦を中心に 3 × 3 区画。島・自艦隊・見えている敵・港などの印。海全体は描かない。
- **海図 (別の画面、戦闘画面の上に重ねて開く):** 16 × 16 区画の全体。探索済みの区画だけ色が付き、まだの区画は霧。港・資源・要塞・見つけた敵艦隊の印。タップで行き先を置くと、航路 (区画の上の A* 探索、陸と浅瀬を避ける) と、行き先と帰りに要る燃料が出る。閉じると戦闘画面に戻り、AUTO なら航路をたどる。
- 海図を開いている間、時間は止まる。

#### 5. 港・資源・要塞 (海の上の本物の場所)
- **港:** 港の円に入ると入港の帯が出る (補給 100・応急修理 60%・帰港)。軍港の円では「帰港」だけ。
- **油田・鉱山:** 円の中を通ると資源 (今と同じ量、1 時間に 1 回)。
- **船団の航路:** 段階 A では、航路の起点に船団 (輸送船 2〜3 隻と護衛) が止まっている。現れたら、沈めると資源 (段階 B で動き出す)。
- **要塞:** 要塞の島に近づくと、陣地 (今の対地攻撃の地上兵器) と守備艦隊が現れ、その場で対地攻撃になる。上陸支援・機雷原・防潜網も今の仕組みのまま区画に置ける。

#### 6. 敵艦隊 (段階 A は動かない)
- 今の「1 時間ごとの敵艦隊 (輪ごとに 1 つ)」を、危険度に応じた区画に置く。数は区画の危険度で 6〜12 個。
- 勝った敵艦隊はその 1 時間は戻らない (今の `cleared` と同じ)。友軍の巡回・史実の海戦も同じ置き方で区画に置く。
- 動き出すのは段階 B。

#### 7. 視界と探索
- 今の霧 (`FogOfWar`) は画面の大きさで描いているので、広い海でもそのまま使える。
- 探索済みの区画 (16 × 16 = 256 個の 0/1) を保存し、海図の霧を晴らす。

#### 8. 燃料
- 今の「補給 100」を燃料タンクとして残す。減り方は走った距離 (今の航行距離の記録 `sailedPx` と同じ数え方) で、1 区画で約 3。
- 海図で、今いる所から軍港・最寄りの港までの燃料を出す。帰りの分を切ったら警告し、AUTO なら最寄りの港へ向ける。

#### 9. 重さ (CPU ×4 で 1 フレーム 8 ms 以下を保つ)
- 当たり判定のある島は 3 × 3 区画分だけ。現れている敵は 30 隻まで。早送り ×8 の時は、AI と霧の計算を 1/2 の頻度に落とす。
- `npm run perf` に「広い海を ×8 で 2 分走る」測り方を足す。

#### 10. 保存
- 航海中の位置 (海の座標)・向き・燃料・探索済みの区画・勝った敵艦隊を保存する。交戦中にゲームを閉じた時は、交戦の前の位置に戻して再開する (今の出撃の中断と同じ考え)。
- 今の `world` (航海中の艦隊・制海権・訪れた場所・要塞) は、軍港から始め直す形で読み替える。

#### 11. テスト
- 純粋な仕組み (Vitest): `WorldGrid` (区画の読み出し・陸の判定・危険度)、`WorldRoute` (航路と燃料)、`SectorWindow` (どの区画を読み込むか)、敵の出し入れの判定、交戦の精算 (報酬・損傷・任務)。
- E2E (縦・横): 外洋の戦闘画面・ミニマップ・海図の重なりとはみ出し。軍港 → 敵艦隊 → 交戦 → 精算 → 港 → 帰港の一連を、早送りと AUTO で流す。
- 模擬: 外洋の交戦を各危険度で流し、勝率と損傷を見る。

#### 12. 作る順番 (段階 A の中)
1. `WORLD` を変えられるようにし、`SectorStreamer` で 2 × 2 区画の試しの海を走れるようにする (敵なし)。
2. 区画のデータと生成スクリプト、データ検査。
3. 海図の画面と航路・燃料・早送り。
4. 敵の出し入れと `settleEngagement()` (戦闘画面のまま交戦して精算)。
5. 港・資源・要塞・船団を海の上の場所にする。今の外洋の画面 (`WorldMapScene`) を外す。
6. 保存の読み替え・勲章・ヘルプ・E2E・模擬・バランス確認。

段階 A は大きいので、1〜3 と 4〜6 の 2 版に分けてもよい。

### 段階 B 動く世界
**世界の時計**
- 本物の 1 分 = 世界の 1 時間 (案)。昼夜は世界の時刻で決まり、戦闘の時刻 (昼・夜) もそれに従う。
- 天候は前線 (雨・霧・嵐の帯) が区画の上を流れる。嵐の区画は速力が落ち、視界が狭い。

**住人 (`WorldSim`)**
- 敵艦隊・船団・友軍の巡回は「航路」と「状態」を持つ。状態は 巡回 → 発見 → 追跡 / 逃走 → 見失う → 巡回。
- 発見した時に、自分と相手の総戦力 (今の `fleetPower`) を比べて、追うか逃げるかを決める。
- 船団は港と港の間を往来する。襲うと資源が入り、護衛が付いていることがある。
- 友軍の巡回は自国の区画を回り、近くの戦闘に加わる (今の「友」と同じ働き)。
- 住人は 60 まで。画面の外は 1 秒に 10 回、画面の中は毎フレーム動かす。数と配置は世界の時刻と固定した種で決まるので、保存するのは「沈めた」「動きが変わった」ものだけ。

**出会いの選び方**
- 「交戦」「回避」「追撃」を選べる。回避は速い方が逃げ切れる (速力の差と天候で決まる)。逃げた敵を追撃すると、敵が背を向けた形で戦闘が始まる。

**遊んでいない間**
- 開いた時に、経過した世界の時間だけ `WorldSim` を進める (上限は世界の 24 時間)。航海中の艦隊は止まって待つ (勝手に戦わない)。

**勲章・任務**
- 「船団襲撃」「追撃戦」「回避」の勲章。任務に「船団を N 回襲う」。

### 段階 C 領域と戦略
**区画の制海権**
- 区画ごとに持ち主と強さ (0〜100)。勝つと自国の強さが上がり、敵の巡回が通ると下がる。強さ 50 以上の区画は自国のもの。
- 今の作戦の「制海権」(#50、海域ごと) とは別の数字だが、作戦の海域の制海権が外洋の対応する区画の強さを少し上げる (逆も)。

**敵の反攻**
- 自国の区画が増えると、敵の反攻艦隊が実際に航路を通ってやって来る。止めないと区画を取り返される。

**補給線 (#50)**
- 港・前線基地から自国の区画でつながっている範囲は、燃料が減りにくく、港の応急修理の上限が上がる。つながりが切れると、その先の区画の強さが少しずつ下がる。

**前線基地と複数の艦隊**
- 要塞を落とした島に前線基地を置ける (今の「軍港と基地」の基地の働きを外洋にも)。
- 航海に出せる艦隊を 2〜3 個にする (今の複数艦隊・支援艦隊の枠を使う)。地図の上で別々に動かせる。

**勲章・任務**
- 「区画の制海権」「反攻の撃退」「補給線」の勲章。

### 段階 D 一つの世界
**7 か国の海をつなぐ**
- 各国の地図を一つの大きな地図につなぐ (国の海の端が隣の国の海につながる)。最初は自国の海だけが見え、探索すると他国の海が開く。
- 他国の海では、その国の艦隊が住人になる。同盟と敵の関係 (今の戦域の敵の決め方) に従って、交戦するかどうかが決まる。

**史実の年表 (#50)**
- 1939〜1945 の年表を持ち、世界の暦が進むと、史実の作戦がその海域に「出来事」として現れる (ミッドウェー作戦の機動部隊が実際に航路を動くなど)。
- 結果が次の出来事を変える (例: ミッドウェーで勝つと、次の出来事の敵が弱い)。

**発見**
- 沈没船 (設計図の断片・部品)、未知の島 (資源の場所が増える)、遭難した艦長 (艦長が手に入る)。探索済みの区画が増えるほど見つかる。

**勲章・任務**
- 「世界一周」(全ての国の海に入る)、「史実の作戦」(出来事を N 回終える)、「発見」の勲章。
