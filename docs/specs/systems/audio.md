# 音の仕様 (Audio, 0.0.49)

実装: `AudioSystem` (WebAudio の合成)、`SoundRules` (効果音の間引き・同時発音の上限・撃沈音の大きさ)、`MusicScore` (曲のデータ)、`VoiceSystem` (声)、`CommentarySystem` (実況とナレーションのキュー)、`FeedbackRules` (画面の揺れと振動)。設定は `SettingsSystem` (`docs/specs/systems/settings.md`)。

## 方針

- **音声ファイルは使わない。**
  - 効果音も BGM も、WebAudio の発振器とノイズでその場で作る。
  - 容量が増えず、録音の権利 (演奏者・レコード会社の権利) も生じない。
- **声は端末の音声合成。** ブラウザの Web Speech API (日本語の声) を使う。
  - 声が無い端末では、字幕だけになる。
- 録音や音声ファイルへの差し替えは、オープンベータの前に改めて判断する (#93)。

## 4 つの系統 (#105)

| 系統 | 内容 | 設定 |
|---|---|---|
| BGM | タイトル・鎮守府・戦闘の曲 | 音量・オン / オフ、国別の曲 / 従来の曲 |
| 効果音 | 砲撃・撃沈・通知など | 音量・オン / オフ |
| ナレーション | 作戦の開始・勝敗・昇進・研究と建造の完了 | 音量・オン / オフ |
| 戦闘実況 | 戦闘中の実況 | 音量・オン / オフ・頻度 (多い / 普通 / 少ない) |

- 全体のミュートは、4 つすべてを止める。
- 字幕 (ナレーションと実況の文字) は、別にオン / オフできる。

## 国別 BGM (#93)

場面ごとの曲:
- **タイトル:** 共通の和音 (従来の曲)。
- **鎮守府と各画面:** 遊んでいる国の曲。
- **戦闘:** 同じ曲を 1.25 倍の速さで。
- **勝利・敗北:** 効果音の短いジングル。

演奏の仕方:
- 楽譜は `src/data/music.json` に「音の高さ:拍」で持つ。
- 金管風の音色 (のこぎり波を低域フィルタに通す) で鳴らす。
- 曲の冒頭の数小節を、短く編曲したものを繰り返す。

### 使う曲と権利の根拠

**楽曲 (作曲) の著作権が切れたものだけを使う。**
- 日本の保護期間は、作者の死後 70 年 (2018 年 12 月 30 日より前に切れたものは、50 年のまま切れている)。
- 外国の曲も、作曲者の没年がいずれも 1941 年以前なので、各国の保護期間 (長くても死後 70 年) を過ぎている。
- 詞は使わない (旋律だけ)。

## 効果音 (#104)

| 種類 | 鳴る時 |
|---|---|
| `sinkLarge` / `sinkMedium` / `sinkSmall` | 敵の撃沈 (戦艦・空母 / 巡洋艦 / 駆逐艦・潜水艦) |
| `ownSink` | 自分の艦の撃沈 (警報と低音) |
| `hit` / `ricochet` / `torpedoHit` | 砲弾の命中 / 装甲に弾かれた (火力の 35% 未満) / 魚雷の命中 |
| `nearMiss` | 旗艦のすぐ脇 (70 px 以内) への着弾 |
| `alarm` | 自分の艦の大破 (耐久 25% 以下) |
| `torpedoLaunch` | 魚雷の発射 |
| `launch` / `plane` / `bombDrop` / `planeDown` / `aaFire` | 発艦 / 敵機 / 爆弾 / 撃墜 / 対空弾幕 |
| `dive` / `surface` / `sonar` | 潜航 / 浮上 / ソナーの探信 |
| `victory` / `defeat` | 勝敗のジングル |
| `notify` | 研究完了・建造完了 |
| `ui` / `uiBack` | ボタン (決定 / 戻る・閉じる) |

- 同じ種類は最小間隔で間引く。
- 同時に鳴るのは 14 まで (`MAX_SOUNDS`)。ただし、撃沈・警報・勝敗・通知・ボタンの音は上限があっても鳴らす。

## 戦闘実況とナレーション (#106)

実況のキュー (`CommentarySystem`):
- 種類ごとに優先度と間隔を持つ。
  - 優先度の高い実況 (旗艦の危機・撃沈) が先に流れる。
  - 同じ種類は、間隔の間は繰り返さない。
- 頻度の設定で、間隔が変わる (少ない = 2 倍、多い = 半分)。
  - 「少ない」では、優先度 4 未満の実況は流さない。
- 4 秒以上待った小さな実況は捨てる (もう合わないため)。
- 1 本の実況が終わる (2.6 秒) まで、次は流さない。

文言と字幕:
- 文言は `src/data/commentary.json` にある。国ごとの言い回しが、共通の文言より優先される。
- 字幕は戦闘画面の下に 3 秒出す。
- 結果画面の「戦闘ログ」で、実況の履歴を見られる。

## 揺れと振動 (#107)

- **画面の揺れ:**
  - 揺れる時: 敵の撃沈 (大型ほど強い)、自分の艦の撃沈・大破・被弾、旗艦への至近弾。
  - 遠いほど弱く、1,600 px より遠ければ揺れない。
  - 設定は 弱 (既定) / 強 / なし。
- **振動 (`navigator.vibrate`):**
  - 震える時: 自分の艦の被弾・大破・撃沈、敵の大型艦の撃沈。
  - iOS の Safari と PC では何もしない。
