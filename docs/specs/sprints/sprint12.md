# Sprint 12 — プレイテストのフィードバック対応 (Issue #15〜#30)

**Status**: Implemented [IMPLEMENTED: sprint12] | **Branch**: `ccr-192e7779-941xlk` (PR #14 に同梱)
**Goal**: 駆逐艦 1 隻・資源 0 から国ごとの鎮守府で成り上がる「成長の流れ」を作り、艦・国・艦長・研究・改造を大きく増やす。
UI の不満 (ページ送り・英語の国名・入渠表示) と、戦闘の狭さ・ミッドウェーの難しさを直す。

## 方針の決定 (ユーザーから一任)
| Issue | 決定 |
|---|---|
| #15 演習 | 演習は**損傷なし・出撃コスト無料**。開始時は満タン HP (作戦の損傷を持ち込まない)。入渠中の艦も使える。熟練度・艦長 XP・戦績は残す。資源報酬は**半分**。 |
| #18 駆逐艦スタート | 艦は「保有」制。新規は**その国の駆逐艦 1 隻**から。入手は ① 工廠の**建造** (#29) ② 作戦の**初回攻略報酬** (海域ごとに 1 隻)。建造できる艦種は研究で解放 (`build_cruiser` → `build_battleship`、`build_carrier`、`build_submarine`)。演習・作戦は保有艦のみ。史実シナリオは指定艦なので対象外。 |
| #25 隻数 | 出撃枠は**提督の階級** (#30) で 1→2→3→4→5→6。敵の隻数は海域ごとに 1〜8。演習の敵隻数は「自軍と同数 / +1 / +2」から選ぶ。 |
| #27 国別 | **1 つのセーブで全国を並行して遊べる**。鎮守府で国を切り替える。国ごと: 資源・入渠・研究・保有艦・改装・改造・熟練度・艦長 XP・作戦の進み具合・提督の階級。全体で共有: 戦績・勲章・設定。旧セーブは日本に引き継ぐ。 |
| #28 資源 0 | 新しい国は**資源 0** から。**時間で自然回復** (燃料・弾薬・鋼材 +3/分、ボーキ +1/分、上限 1500。上限を超えた分は回復しない)。演習は無料、作戦の最初の海域も出撃コスト無料。 |
| #16 艦の種類 | 仕組みは 5 艦種のまま、表示と解放用に**サブ艦種** (`subtype`) を追加: 巡洋戦艦・航空戦艦・重巡・軽巡・軽空母・護衛空母・海防艦。既存国に艦を追加 (各国 +5〜8 隻)。 |
| #17 国の追加 | **フランス (FR)・ソ連 (SU)・イタリア (RM)** を追加。各国 10 隻前後。ソ連の空母は架空艦扱い (`fictional`)。戦域は 地中海 (伊・仏) と バルト海 (ソ連 vs ドイツ) を追加。 |
| #19 研究・改造 | 研究は系統ごとに I〜V。新系統: 航空・対潜・夜戦・補給 (資源の回復量)・建造技術。改造は **改三** を追加し、主力艦 (大和・アイオワ・ビスマルク など) に**専用改造**。改装スロットは改造段階で 2→3→4。 |
| #20 スクロール | 艦隊編成と図鑑の一覧をスクロール (ドラッグ・慣性・ホイール・スクロールバー)。 |
| #21 国名 | 国名は `NATION_INFO[n].jaShort` (日本 / 米国 / ドイツ / 英国 / フランス / ソ連 / イタリア)。英語略称は装飾ラベルだけ。 |
| #22 入渠表示 | 縦向きでは残り時間を進捗バーの下の行に出す。 |
| #23 ミッドウェー | AUTO で勝率を測り、日本側の勝率が 4〜6 割になるまで調整 (制限時間・攻撃隊・米空母の対空)。 |
| #24 艦長 | 各国 8 名、新技能: 航空・対潜・夜戦・索敵・応急。艦長の枠は出撃枠と同じ数。艦長も作戦の初回報酬で加わる。 |
| #26 マップ | 縦横とも**正方形 3200×3200**。射程・視界・速度・AI の巡回を合わせて調整。 |
| #29 (新規) 建造 | 工廠に「建造」タブ。資源を消費して艦を入手 (保有艦を増やす)。同じ艦は 1 隻まで。 |
| #30 (新規) 提督の階級 | 作戦の攻略数で 少佐→中佐→大佐→少将→中将→大将。階級で出撃枠と建造できる艦の格が上がる。 |
