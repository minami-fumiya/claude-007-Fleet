# 通し番号 (No.) の採番ルール (#249)

艦・艦長・航空機・地上目標・兵装・アイテムには、重複のない 7 桁の番号 (No.) を振る。
番号は図鑑と建造画面に「No.1101003」の形で出る。
セーブは今までどおり文字列の id で記録するので、番号を足しても変えても、セーブは壊れない。

## 形式

| 桁 | 意味 | 例 |
|---|---|---|
| 1 桁目 | 分類 | 1 = 艦 |
| 2 桁目 | 国 | 1 = 日本 |
| 3〜4 桁目 | 種別 | 01 = 戦艦 |
| 5〜7 桁目 | 連番 (001〜999) | 003 = 3 番目 |

例: `1101003` は、艦・日本・戦艦の 3 番目 (長門) を表す。

## 連番の決め方
- 最初の採番 (0.0.34) は、古い順に振った。
  - 艦は、一覧の並び順 (#246) で振った。艦型 (級) の古い順で、同じ級の中は 1 番艦から順。
  - 艦以外は、データの順で振った。
- **一度振った番号は変えない。** 後から足す要素は、同じ分類・国・種別の空いている一番小さい連番をもらう。
- 番号を足す手順:
  1. JSON にデータを足す (`no` は書かない)。同型艦は `scripts/gen-ships.ts` の表に足す。
  2. `npx vite-node scripts/gen-ships.ts` を実行する (同型艦を足した時だけ)。
  3. `npx vite-node scripts/gen-numbers.ts` を実行する。番号のない要素に番号が付く。
  4. `npm run test` で `tests/unit/Numbering.test.ts` が通ることを確かめる。

## 新しい国・種別を足す時
- 国は `src/systems/Numbering.ts` の `NATION_CODE` に、空いている番号 (8, 9) で足す。
- 種別は、その分類の表 (`SHIP_TYPE_CODE` など) に、空いている番号で足す。
- 足した番号は、この文書の表にも書く。
- 連番が 999 を超えそうな時 (例: 1 国の駆逐艦が 999 隻を超える時) は、同じ分類に別の種別番号を足して分ける。

## 検査
`tests/unit/Numbering.test.ts` で、次のことを確かめる。
- すべての要素に番号がある。
- 番号が重複していない。
- 分類・国・種別の桁が、その要素の中身と合っている。
- 同じ級の中では、番号が番艦の順に並んでいる。
