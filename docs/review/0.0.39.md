# 0.01 区切りの総点検 — 0.0.39-alpha の公開後 (2026-10-21)

CLAUDE.md の「0.01 区切りの総点検」の 1 回目。0.0.39 を公開した後、0.0.40 に入る前に、次の 4 つを見た。
- パワーバランス
- 抜け漏れ
- バグ
- issue の読み直し

追跡は #323。総点検で直したものは、この点検の PR に入れた (0.0.40 に入る)。

## 1. パワーバランス

`npm run balance` と、ゲームの関数を呼ぶ計算で調べた。比べた範囲は 0.0.28 → 0.0.39 の変化。

### 艦の強さ
- 艦種の順 (戦艦 > 巡洋艦 > 駆逐艦) と、格の順は崩れていない (テストが通る)。
- テストが見ていない所に外れ値がある → #319。

| 艦 | 内容 |
|---|---|
| ドイチュラント | ヒッパー級重巡より 25% 強い |
| 隼鷹 | 加賀の 0.75 倍 |
| ギアリング | サムナーの 0.84 倍 |
| ソ連の 1914 年の戦艦 | 大和と同じ火力 |
| 英国の重巡 | 全国で最も弱い |
| 架空空母 (格 5) | 艦載機が 7〜9 機で、史実の格 3 (13〜14 機) より少ない |

- 各国の最強艦の差は、戦艦 1.30 倍・重巡 1.66 倍・軽巡 1.32 倍・駆逐艦 1.46 倍・空母 (艦載機) 2.1 倍。

### 作戦の難しさ (敵の戦力 ÷ 曲線の目安)
- **南太平洋は、深くなるほど弱くなっていた。**
  - p5 3,093 (2.44 倍) → p8 2,715 → p9 2,293 と下がり、最終の p6 は 3,448 (0.81 倍)。
  - **総点検で直した:**
    - p5 から重巡デモインを外した (2.44 → 1.93 倍)。
    - p6 に戦艦サウスダコタを足した (0.81 → 1.08 倍)。
- **平らな区間:** 南大西洋 sa3 → sa4 → sa7 (sa7 は 0.73 倍で最も低い)、北太平洋 np4 → np7、黒海の終盤 → #293 に追記。
- **推奨階級は、実際に着く階級より 2〜4 段低い:**
  - 山場では、推奨階級の艦隊が敵の 0.5〜0.7 倍しかない。
  - 「深さ + 1」にすると、ほぼ全海域で 1.0 倍以上になる → #293 に追記。

### 資源 (1 時間)
| 時期 | 燃 / 弾 / 鋼 / ボの差し引き | 余りで建造できる数 (燃 / 弾 / 鋼) |
|---|---|---|
| 序盤 (吹雪) | 2,456 / 2,369 / 3,040 / 753 | 22.3 / 21.5 / 17.9 |
| 中盤 (高雄) | 1,403 / 1,610 / 2,581 / 756 | 4.4 / 4.5 / 4.3 |
| 終盤 (長門) | 899 / 1,215 / 3,570 / 330 | 1.1 / 1.2 / 2.0 |

- 差し引きがマイナスの資源は無い。0.0.39 の目安 (鋼材 ≥ 燃料・弾薬の 8 割、3 倍以内) も満たす。
- **終盤の燃料が、0.0.28 の水準に戻っていた。**
  - 戦闘の燃料の報酬は、敵の艦種で変わらなかった (撃沈 1 隻 80)。そのため、出撃と修理の燃料だけが 2.2 倍に増えていた。
  - **総点検で直した:** 撃沈の燃料を艦種ごとにした (戦艦 130・空母 110・巡洋艦 90・駆逐艦 70・潜水艦 60)。
  - 終盤に燃料で建造できる長門は 1.1 → 1.6 隻。序盤は 22.3 → 21.8 隻で、目安の中。
- **時短アイテムが割に合わない:**
  - 高速修理材・高速建造材で縮むのは数分。値段はゴールド 1.5〜2 時間分。
  - 経済モデルは、空母の建造 (ボーキ)・軍港の割引・ショップの交換を見ていない → #321。

### 時間
- 建造は駆逐艦 1 分〜戦艦 7.5 分 (架空戦艦 11 分)。大破からの入渠は最長 3.6 分。どちらも 1 戦より短い。
- 一番長いのは軍港の工事 (20〜60 分)。1 回だけなので許容範囲。

### 育成と昇進
- **熟練度:** 3 隻沈める戦いなら、5 戦で改三の条件 (90) に届く。プレイテストの「早すぎる」は数字のとおり → #305 に式の案を追記。
- **戦功:** 初回攻略の戦功だけで約 4,125 になる (日本の 33 海域、元帥の 1.65 倍)。格 5 は約 10 海域で開く → #322。
- **艦長:** 習得枠 4・5 まで 68・212 時間かかる → #322。
  - 艦長教本は 1 冊 300 経験値 (1.6 戦分) で、600 G の値段に合わなかった。
  - **総点検で直した:** 1,000 経験値にした。
- 熟練度・艦長の経験値・戦功の表は、0.0.28 から 12 版のあいだ一度も見直していなかった。

### 報酬
- 任務の収入は、戦闘の 0.40 倍 (目安 0.3〜0.5 の中)。
- デイリーの目標は、1 日 2 時間の遊びの約 2 倍、ウィークリーは 1 週の約 4 倍の量が要る。
  - #266 (毎時の 10 倍・100 倍) で決めた重さなので、変えるかどうかをユーザーに確認する (#323)。
- ゴールドは 1 時間に約 190 G。0.0.32 の見積もり (約 300 G) より、ウィークリーの達成率と S の厳しさで減った → #321。
- S 評価が実際にどのくらい取れるかは、模擬が無いので確かめられていない → #320。

## 2. 抜け漏れ

0.0.20〜0.0.39 の 42 の要素について、勲章・任務・図鑑・ヘルプ・昇進条件・データ検査がそろっているかを表にした。

### 問題の無かったもの
- 任務の事象 62 種は、どれも勲章か任務に使われていた。どれにも、出す所があった。
- 条件を満たせない勲章は無かった。
- 出所か使い道の無いアイテムは無かった。
- ヘルプの id は、どれも画面の名前と一致した。

### 総点検で直したもの
- **古い説明:**
  - 建造の時間 (「戦艦 1 時間」→「7 分ほど」・ドックは入渠と共用)
  - 鎮守府のメニューの説明 (工廠にショップ)
  - 軍港の「移動と施設」→「開港と施設」
  - 図鑑の飛行場 (「今後、航空機を出撃させる」→ 今の動き)
  - 図鑑の絞り込みの説明
- **アイテムの入手方法:**
  - 高速修理材から、実際には無い「作戦の報酬」を外した。
  - ゴールドに、資源の売却・超兵器の撃沈・史実の初勝利を足した。
- **ヘルプ:**
  - 作戦に掃討と戦力の比較
  - 改装に改三の方向
  - 編成に艦長の自動配属
  - 操作に弾種と一時停止
- **データ検査:**
  - ヘルプの id が画面の名前にあること
  - メニューから開ける画面に説明があること
  - アイテムの使う画面があること
  - 改造の対象の艦があること
- **勲章と任務:**
  - 昇進章に元帥の段 (特等) を足した。
  - 戦果任務「黒海の覇者」を足した (ほかの 8 戦域とそろえた)。

### issue にしたもの
- **#314 任務:**
  - 0.0.33〜0.0.39 の戦闘の要素に任務が無い (火災・陸上目標・飛行場・難易度・寡兵・無傷・超兵器)。
  - 育成・工廠の事象に任務が無い。
  - 史実では任務が数えられない。
  - 軍港の開港・ドックの増設を数える事象が無い。
- **#315 記録:** アイテムを使った数の勲章が無い。図鑑に超兵器が無い。
- **#316 ヘルプ:** 評価・戦闘の仕組み・イベントのタブが無い。設定・戦闘結果・国の選択の説明が無い。
- **#317 史実:** フランス・ソ連の史実シナリオが 0 本。
- **#318 品質:** 事象の一覧を実行時の値にし、関連要素と版の計画をテストで確かめる。
- **#261 に追記:** 昇進任務が 0.0.19 のまま。

## 3. バグ

全 16 画面を縦・横で開いて写真で確かめた。中盤のセーブで、入渠中・建造中・損傷艦・開港 2 港の状態。戦闘結果の画面 (「S まで」の行) も見た。

- 画面の崩れ・はみ出し・重なりは、E2E (0.0.39 で重なりの検査を必須にした) と同じく見つからなかった。
- **工廠:** ドックが満杯の時、「建造できる」の絞り込みで「この条件の艦はありません (絞り込みを変えてください)」と出て、理由が分からなかった。
  - **総点検で直した:** 「ドックが空いていません (入渠か建造が終わると、また建造できます)」と出す。
- **戦闘結果:** 縦画面では、「S まで: …」の行が小さく縮む (読めるが小さい)。#316 のヘルプのタブで評価の条件を説明して補う。
- プレイテスト第 15 弾の不具合 (#303: 国切替の階級・建造 0 秒・自然回復欄・資源不足の詳細・艦長教本) は、0.0.40 で直す。
