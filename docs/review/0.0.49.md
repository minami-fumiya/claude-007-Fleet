# 0.01 区切りの総点検 — 0.0.49-alpha の公開後 (2026-10-28)

CLAUDE.md の「0.01 区切りの総点検」の 2 回目。0.0.49 を公開した後、0.0.50 に入る前に、次の 4 つを見た。
- パワーバランス
- 抜け漏れ
- バグ
- issue の読み直し

追跡は #371。総点検で直したものは、この点検の PR に入れた (0.0.50 に入る)。前回は `docs/review/0.0.39.md`。

## 1. パワーバランス

`npm run balance`・戦闘の模擬 (`npm run sim -- --grown 1 --sample 1 --runs 2`)・ゲームの関数を呼ぶ計算で調べた。比べた範囲は 0.0.39 → 0.0.49 の変化。

### 戦闘の模擬 (前回の宿題: S の割合と、推奨階級の艦隊の勝率)

育成済みの艦隊で、各国・各戦域の最初・中ほど・最後の海域を 2 回ずつ (96 か所)。0.0.39 には模擬が無かったので、比べるのは 0.0.48 の結果。

| | 0.0.48 | 0.0.49 |
|---|---|---|
| 勝率 | 95% | **96%** |
| 日本 / 米国 / ドイツ / 英国 | 100 / 96 / 100 / 100% | 100 / 93 / 100 / 97% |
| フランス / ソ連 / イタリア | 100 / 86 / 77% | 96 / 88 / **96**% |
| S の割合 | 26% | 21% |
| 戦闘時間の中央値 | 15 秒 | 16 秒 |

| 推奨階級 | 海域 | 勝率 | 敵 / 自 |
|---|---|---|---|
| 准尉〜大尉 | 36 | 93% | 0.44 |
| 准佐〜少佐 | 5 | 100% | 0.65 |
| 中佐〜大佐 | 11 | 91% | 1.19 |
| 准将〜 | 41 | 99% | 2.00 |

- **2 回の模擬はぶれが大きい。** 0% や 50% の海域を 4 回ずつ流し直した。

| 海域 | 2 回 | 4 回 (流し直し) |
|---|---|---|
| 米国の北大西洋 1 (a1、准尉) | 0% | 100% |
| ソ連の北太平洋 4 (np4、中佐) | 0% | 100% (評価は 4 回とも C) |
| イタリアのインド洋 1 (io1、大尉) | 100% | 100% (0.0.48 は 0%、#368) |

- **イタリアのインド洋 1** は、0.0.48 の 0% から 6 戦 6 勝になった。0.0.48 の装備・消耗品の後で、敵の駆逐艦 2 隻に負けなくなった。#368 から外す。
- **残る弱い所** (#368 に引き継ぐ):
  - ソ連の北極海 4 (ar4): 50%。1 回は 900 秒の時間切れ (霧の中で残りの陣地が見つからない)。
  - フランス・イタリアの南大西洋 1 (sa1): 50%。模擬の艦隊に対潜の艦が入らない (敵は潜水艦)。
- **S の割合 (21%)** は、国で大きく違う: 米国 50%・英国 37% に対して、イタリア 4%・日本 6%・ソ連 8%。ソ連の北太平洋 4 は勝っても C。
- 模擬の途中で 3 か所 (日本の地中海 1・6、北太平洋 1) が止まった。模擬が使う開発サーバーが、ソースの書き換えで画面を読み直したため。流し直すと 3 か所とも 4 戦 4 勝。模擬の間はソースを書き換えないこと。

## 2. 抜け漏れ

0.0.40〜0.0.49 の約 60 の要素について、勲章・任務・図鑑・ヘルプ・データ検査がそろっているかを見た。

### 問題の無かったもの
- **勲章:** 新しい要素には、どれも勲章がある (0.0.39 の 255 → 350)。
  - 例: 遠征・寮舎・給糧・士気・支援艦隊・友軍・装備開発・部品・設計図・超兵器海域・航空機・エース・地上兵器・消耗品・解体・自動編成・陣形・戦闘記録。
- **任務の事象:** 0.0.40 から、使われない事象はデータ検査が拾う (#318)。今は全部どれかに使われている。
- **図鑑:** 航空機 (#87) と地上兵器 (#251) のタブがある。

### 総点検で直したもの
- **戦闘のヘルプ:** 0.0.43 以降の戦闘の要素の説明が無かった。足した:
  - 消耗品、士気、支援艦隊・友軍、地上兵器、実況と字幕
  - 超兵器の説明が 0.0.48 より前のまま (イベントだけ) だったのを、超兵器海域と設計図に直した。
- **戦闘結果のヘルプ:** 0.0.49 で足した「戦闘ログ」の説明が無かった。
- **ヘルプのスクロール:** 戦闘のタブが縦画面でパネルからはみ出した (足した説明のため)。行が多いタブはスクロールするようにした。E2E で全タブの写真も撮る。

### 0.0.50 に回すもの (#371)
- **図鑑に装備が無い:** 装備 25 種 (#55 #251 #150) と消耗品は、図鑑に載らない (勲章「装備収集章」はある)。図鑑に「装備」のタブを足す。
- **艦長の習得枠 4・5 が遠い** (上の表)。
- **ソ連の元帥の試験が軽い** (上)。

## 3. バグ

  - 札の幅を、枠の丸い角を含めずに測っていたため。**総点検で直した。**
