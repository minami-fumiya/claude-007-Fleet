## 1. パワーバランス

調べ方は次の 3 つで、比べた範囲は 0.0.49 → 0.0.59 の変化です。
- `npm run balance`
- 戦闘の模擬 (`npm run sim -- --grown 1 --sample 1 --runs 3`)
- ゲームの関数を呼ぶ計算

### 戦闘の模擬 (前回の宿題: 回数を増やして、S の割合の国による差を見る)

SIM_SECTION

### 資源 (1 時間)

0.0.49 とほぼ同じです。差し引きの違いは、どの段階でも 1 時間 ±4 以内でした。

| 段階 | 差し引き (燃 / 弾 / 鋼 / ボ) | 収入 ÷ 支出 (燃料) | ゴールド |
|---|---|---|---|
| 序盤 | 2,233 / 2,217 / 3,038 / 719 | 2.88 | 272 G |
| 中盤 | 1,163 / 1,334 / 2,189 / 487 | 1.41 | 238 G |
| 終盤 | 985 / 892 / 3,182 / 843 | 1.24 | 203 G |

- **ショップ (0.0.58):** 上限を 1 時間にしたので、ゴールドが決め手になります。1 時間のゴールドを一番得な交換に全部使っても、1 時間の戦闘の収入より少ないです (テストで確かめています)。
- **終盤の鋼材:** 1 時間に 3,000 余ります (収入 ÷ 支出 2.31)。使い道は次の 3 つです。量としては足りていますが、次の総点検でも見ます。
  - 建造
  - 設計艦 (0.0.52)
  - 売る (1 時間に 5,000 まで、0.0.58)

### 時間
建造・入渠・施設の時間は、0.0.49 から変えていません。士気は 0.0.58 から、時間で 100 まで上がるようになりました (50 → ★ 70 は 3 時間 20 分)。

### 育成と昇進
0.0.58 で、昇進任務を「前の昇進から数える」ように変えました。
- 目標の数は、1 階級の間に遊ぶ量に合わせて下げました。例えば中佐は、撃沈 40・潜水艦 5・勝利 12 です。
- 「6 隻以上の敵艦隊に S」は、その艦隊が出る海域に、今の階級で行ける昇進だけに使います (中将・元帥)。データ検査で守ります (#407)。
- 研究の Lv9 / Lv10 は准将 / 少将で開きます。准将で開く研究は、1 つから 11 になりました (#405)。

### 報酬
- 勲章は 350 (0.0.49) → 448 です。任務は 237 です。
- 0.0.55 で、イベントの任務が各イベント 10 件になりました。
- 報酬の値は 0.0.49 から大きくは変えていません。

## 2. 抜け漏れ

0.0.50〜0.0.59 の約 70 の要素について、次の 5 つがそろっているかを見ました。
- 勲章
- 任務
- 図鑑
- ヘルプ
- データ検査

### 問題の無かったもの
- **勲章:** 新しい要素には、どれも勲章があります。例:
  - 軍港と基地の施設
  - 通算の記録と称号
  - 固有スキル
  - 艦隊技術
  - 国家方針
  - 設計艦
  - 装備改修
  - 他国艦
  - 音楽室
  - 図鑑の収集率
  - イベントの完遂
  - 総力演習
  - おまかせ開発 (福引章)
  - 友軍の断片 (供与章)
- 次の 2 つは新しい要素ではないので、勲章は足していません。
  - 国の 1 国ずつの解禁: 今ある「連合章」が数えます。
  - 「掃討できる海域」: 案内と移動を足しただけです。
- **任務の事象:** 使われない事象は、データ検査が拾います。今は全部どれかに使われています。
- **図鑑:** 装備のタブ (0.0.50) と音楽室のタブ (0.0.54) があります。
- **データ検査 (0.0.56〜0.0.59 で足したもの):**
  - 作戦目標ごとの台詞
  - 6 隻以上の艦隊と昇進の条件
  - 研究の Lv と階級
  - 文字の最小サイズ (E2E)

### 総点検で直したもの (ヘルプ)
0.0.58 の変更に、ヘルプが追いついていませんでした。足したのは次の 3 つです。
- **国の選択:** 残りの 3 国が、少佐・大佐・准将 (または戦域の攻略) で 1 国ずつ開くこと。
- **鎮守府:** 昇進任務は前の昇進から数えること。階級一覧に出撃コストの上限が出ること。
- **編成:** 編成の保存枠が階級で増え (3 → 5 → 7 → 10)、「›」で次を出すこと。

### 次の版に回すもの

  - 設計艦の見た目

## 3. バグ

- 0.0.56〜0.0.59 の手元の E2E で見つかった次の 4 件は、それぞれの版で公開前に直しました。
