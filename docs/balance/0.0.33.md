# バランス確認 — 0.0.33-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。表は `npm run balance` の出力 (資源の収支は 0.0.32 から変更なし)。

## 難易度 (#100)

| | 易しい | 普通 | 難しい |
|---|---|---|---|
| 敵の照準誤差 | ×1.3 | ×1.0 | ×0.85 |
| 敵の耐久 | ×0.85 | ×1.0 | ×1.15 |
| 敵の旗艦への狙い | −0.15 (より護衛を狙う) | 0 | +0.15 |
| 報酬 (資源・ゴールド) | ×0.8 | ×1.0 | ×1.25 |

- 既定は「普通」で、今までと同じ。報酬の幅 (0.8〜1.25) は、難しさの差より小さめにした。難しいで稼ぐ方が楽、にならないようにするため。
- AUTO の勝率による確認 (易しい 8 割・難しい 4 割の目安) はまだしていない。次の版で、戦闘の記録から見る。

## 敵の陣形 (#82)

- 敵にも陣形の効果がつく (単縦陣 砲 +10% など)。今までは敵には何もなかったので、全体に少しだけ敵が強くなった。
- 輪形陣の敵は旗艦が守られ (−0.25)、こちらの護衛と AUTO は敵旗艦を狙いにくくなる。

## 弾種・火災・浸水 (#48)

- 自動の弾種は目標に合った弾を撃つ。これまで武器ごとに固定だった弾種より、平均の与ダメージは上がる (敵も同じ)。
- 火災: 12 秒 × 毎秒 0.5% = 最大 6%。浸水: 15 秒 × 毎秒 0.35% = 最大 5.25% と速力 −15%。どちらも重なると、1 回の命中より長く効く。
- ダメージコントロール II・III で、起こりやすさと長さが 15% ずつ下がる (両方で ×0.72)。

## 飛行場 (#83)・超兵器 (#148)

- 飛行場の航空隊は軽空母並み (6 機)。耐久が半分で発進が 2 倍遅くなるので、早めに叩く価値がある。
- 超兵器の耐久は大和 (800) の 3〜5 倍 (2,400〜3,000)。部位が壊れると、主砲の装填 ×2・速力 ×0.6・照準誤差 ×1.6 になる。超兵器は 1 日 1 回、3 時間だけ現れる。撃沈のゴールド +500 は、作戦の勝利 10 回分ほど。

## そのほか (0.0.32 から変更なし)

- 艦の強さ・建造と入渠の時間・育成と昇進の速さ・任務とショップは変えていない。
