# バランス確認 — 0.0.73-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。
この版は本当のオープンワールドの段階 B2「遠征と哨戒」(#445、`docs/specs/systems/open-world.md`) と、0.0.72 から回した B1 の残り (船団護衛・脱出阻止・記念日)。作戦の敵・艦・研究・時間の値は 0.0.72 から変えていない。

## 確かめたこと

### 遠征の時間と収入
全 7 か国 × 21 種の遠征で、往復と現地の時間の合計は遠征の時間ちょうど (航路が長くなる時は途中で打ち切る)。
危険度の倍率の平均 (`expeditionDangerMul`):

| 国 | 全遠征 | 軍港からの 13 種 |
|---|---|---|
| IJN | ×0.986 | ×0.973 |
| USN | ×1.010 | ×0.977 |
| RN | ×1.033 | ×0.977 |
| KM | ×0.990 | ×0.973 |
| FR | ×1.007 | ×0.969 |
| RM | ×0.983 | ×0.969 |
| SU | ×0.998 | ×0.981 |

軍港からの遠征は近い海 (危険度 1〜3) なので 2〜3% 減り、海の遠征 (前進遠征拠点) は遠い危険な海なので少し増える。1 時間あたりの収入は経済の表から ±3% 以内 (表の外の値は変えていない)。途中で引き返した遠征は半分になるので、帰投の基準に当たらない強さの艦で送るほど多く入る。

### 遠征の距離 (日本、往復の区画数 / 行き先の危険度)
練習航海 18 / 1 ・長距離練習航海 28 / 2 ・警備任務 32 / 2 ・対潜警戒 52 / 2 ・海上護衛 46 / 2 ・鉱石輸送 56 / 3 ・航空機輸送 76 / 3 ・油田護衛 47 / 2 ・ボーキサイト輸送 68 / 3 ・艦隊決戦支援 72 / 3 ・遠洋船団護衛 79 / 3 ・敵泊地強襲 58 / 3 ・長期哨戒 69 / 3

### 哨戒
哨戒は燃料を使わない (今は)。見つける数は巡回の多さ (0.0.72 で 1,000 区画に 12) と輪の大きさで決まり、1 時間に数回。任務「哨戒」(日 3 回) と勲章「哨戒章」(1 / 20 / 100)。

### 資源・時間・育成・報酬
作戦・建造・入渠・研究の値は変えていない。任務を 2 つ足した (日: 哨戒で 3 回見つける 1,200、週: 遠征で 1,000 区画 ゴールド 150・資源 16,200、ほかの週の任務と同じ大きさ)。

### そのほか
- 勲章: 遠洋航海章 (遠征で 100 / 1,000 / 5,000 区画)・哨戒章 (1 / 20 / 100 回)。勲章の総数は減っていない。
- 保存: 遠征の出た時刻・途中で会った敵・引き返し (`expeditions[].startedAt / checkedAt / met / cut`)、哨戒の命令 (`openSea.anchors[].order.patrol / seen`)、見つけた敵 (`openSea.sightings`)。どれも欠けていれば「航路なし・命令なし」で読む。0.0.72 以前に出た遠征は今までどおり時間だけで帰る。
