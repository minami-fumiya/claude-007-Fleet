# バランス確認 — 0.0.56-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。資源の表は `npm run balance` の出力。
この版は「不具合と表示」(#394 #395 #398)。

## 変えた値

| 項目 | 0.0.55 | 0.0.56 | issue |
|---|---|---|---|
| 支援艦隊の艦長 | 第一艦隊と同じ艦長も乗れた | 1 人の艦長は 1 つの艦隊だけ (重なる艦長は乗らない) | #394 |
| 支援艦隊に選べる編成 | どれでも | 出撃する艦隊と同じ艦しかない編成・ほかの枠の編成は選べない | #394 |
| 建造の一覧の他国艦 | 全部出る | 断片を 1 つ以上持つ国の艦だけ | #395 #386 |
| 戦闘・艦・資源・時間・報酬の値 | — | 変更なし | |

## 確かめたこと

- **支援艦隊の艦長:** 第一艦隊と重なる艦長が乗らなくなるので、同じ艦長を両方に入れていた編成では、支援艦隊の艦長の効果がなくなる。本来 1 人が 2 隻に乗れたのが誤りで、強さは正しい形に戻る。艦はもとから重複を外していた (#84)。
- **他国艦の一覧:** 表示だけの変更。建造の条件 (断片 10 / 20 個) は同じ。
- **表示の変更 (研究欄の説明・台詞・断片の表記・戦闘のまとめ・編成の札・2 列の一覧・遠征の一覧):** 計算に触れない。
- **模擬:** 戦闘と艦隊の計算は変えていない。全海域の流し直しは 0.0.57 (#400) で行う。
- **資源の表:** 0.0.55 と同じ。
- **勲章:** この版は不具合と表示の直しで、新しい要素 (画面・仕組み・アイテム・遊び方) は足していないので、勲章は増やしていない。
