# バランス確認 — 0.0.30-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。表は `npm run balance` の出力。

## 改造の方向 (#86)

- 改三の方向は「標準より何かを下げて、何かを伸ばす」形。単体テストで、どの方向も標準の改三に全項目で勝たないことを確かめる。
- 研究 (全 I〜V) と合わせた上限は今までどおり (耐久 ×1.65・砲火力 ×1.4・魚雷 ×1.75・速力 ×1.22・ソナー / 爆雷 ×1.65 など)。
  - 上限に合わせて調整した値: 戦艦の主砲換装 砲火力 ×1.22 → ×1.20、巡洋艦の重雷装 魚雷 ×1.40 → ×1.35、駆逐艦の対潜 ソナー・爆雷 ×1.35 → ×1.30、駆逐艦の高速化・潜水艦のシュノーケル 速力 ×1.12 → ×1.10。
  - 搭載機の上限だけ +2 → +3 にした (空母の搭載機増加 +2 と研究 +1)。代わりに耐久・装甲・対空が標準より下がる。

## 海域 (#202)

- 黒海 (ソ連): 敵の数はバルト海と同じ並び (1 → 2 → 3 → 4 → 7 隻)。ドイツ艦 (駆逐艦・軽巡・重巡・装甲艦) が相手。報酬もバルト海と同じ水準。
- 訓練海域: 敵 1 隻・報酬と経験・戦功は半分。初回報酬は燃料・弾薬・鋼材 100 ずつ。稼ぎの場にならないよう、通常の海域より割が悪い。
- 黒海の最終海域は昇進試験に数えない (今の元帥の降格を防ぐ)。

## 艦 (#85)

- 英国 61 隻・ドイツ 32 隻 (同型艦を含む)。同型艦は 1 番艦と同じ性能なので、強さの順は変わらない。全 580 隻。

## 資源の収支 (0.0.28 から変更なし)

- 収支の値は変えていない。終盤は燃料が建造の上限 (長門 1.1 隻 / 時) で、目安 (収入 ≥ 支出の 8 割) は満たす。0.0.31 の任務の報酬見直し (#180) で燃料を足す候補にする。
