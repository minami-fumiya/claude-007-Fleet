## 確かめたこと

### 主砲 2 基の強さ (`BalanceModel.shipDps`、相手は戦艦・装甲 50)
各国の一番強い戦艦 (史実艦と計画艦、設計艦は除く) を 1 として、合法な設計 (副砲 1 つまで含む) の一番強いもの。

| 国 | 基準の艦 | 戦艦船体・段階 1 (主砲 1 / 2) | 戦艦船体・段階 3 (1 / 2) | 超大型戦艦船体・段階 3 (1 / 2) |
|---|---|---|---|---|
| IJN | 大和 | 1.00 / 0.89 | 1.00 / 1.02 | 1.00 / 1.12 |
| USN | モンタナ | 1.12 / 1.11 | 1.12 / 1.11 | 1.12 / 1.18 |
| KM | H39 | 1.02 / 0.95 | 1.02 / 1.06 | 1.02 / 1.10 |
| RN | ライオン | 1.14 / 1.02 | 1.14 / 1.11 | 1.14 / 1.22 |
| FR | リシュリュー | 1.00 / 0.97 | 1.00 / 1.09 | 1.00 / 1.09 |
| RM | ヴィットリオ・ヴェネト | 1.00 / 0.94 | 1.00 / 1.06 | 1.00 / 1.06 |
| SU | ソビエツキー・ソユーズ | 1.00 / 0.87 | 1.00 / 0.97 | 1.00 / 0.97 |

- 装填を遅くしないと 2 基の設計は 1.4〜2.0 倍になった (大和の 46cm + 51cm で 1.96 倍)。×1.6 では米国の 16in 4 連装 + 8in が 1.39 倍。×1.75 で全国 1.22 倍以下にした。
- 主砲 2 基は重さを使い切るため、装甲強化・機関強化・バルジは載らない。主砲 1 つ + 装備と比べて「射程の違う 2 つの砲で撃ち分ける・火力は少し上・耐久と装甲は下」の選び方になる。段階 1 では 1 つの方が強い。
- 上限は「各国の一番強い戦艦の 1.4 倍まで」を `tests/unit/Design071.test.ts` で確かめる (超兵器は大和の 3〜5 倍の耐久なので、それより十分下)。

### 設計段階のお知らせ
設計段階は 方針 3 つごとに 1 + 研究「架空艦計画」で 1 (0〜3)。お知らせは段階ごとに 1 回。0.0.70 以前のセーブで段階が上がっていると、最初に 1 回だけ出る (設計の画面を開くと消える)。
