# バランス確認 — 0.0.70-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。
この版は本当のオープンワールドの段階 A2b (#445、`docs/specs/systems/open-world.md`)。作戦はすべて海の上で戦い、今の外洋の画面の要素 (港・資源・要塞) を世界の地図に移し、停泊地ごとの編成・入渠・艦隊の分離・訓練海域と演習場を入れた。作戦の敵・報酬・艦・研究・時間の値は 0.0.69 から変えていない。

- 資源の量は 危険度 × 今の量なので、遠い場所ほど多い。遠い場所は前線の基地に停泊してから寄る。
- **英国のブレスト・ドイツのスカパ・フロー・イタリアのマルタ・ソ連のキール** は、本拠地のすぐ近くに危険度 9 の要塞がある。序盤の艦隊が知らずに近づかないよう、船団と要塞は赤い輪と「敵の要塞・危険度 9」の名前を海の上に描いた。
- 米国の港 (エスピリトゥサント・真珠湾の港) とアバダン油田は、本拠地から満タンでは届かない (前線の基地から寄る)。

### 訓練海域・演習場
どの国も、訓練海域は軍港から燃料 3、演習場は 3〜5。作戦海域・基地・港などの区画は避けた (`tests/unit/OpenSea070.test.ts`)。

### 作戦目標の時間
突破 (2 分以内) や遅滞は、0.0.69 の作りのまま海域の端 (中心から 3,200 px 以上) で始まると間に合わない。目標のある海域は中心から 1,900 px で始まるようにした (普通の戦闘は約 1,100 px 南から始まり、突破の地点まで約 2,400 px)。殲滅・撃沈目標は 0.0.69 のまま海域に入った時に始まる。

### 資源の表 (`npm run balance`)
任務を 2 つ足した (日: 演習場、週: 洋上作戦) が、掲示される任務の平均で数えるため、差し引きはほぼ同じ (序盤 2,251 / 2,223 / 3,051 / 720、中盤 1,130 / 1,244 / 2,197 / 526、終盤 963 / 807 / 3,211 / 897)。港・資源・船団・要塞は今の外洋と同じ量なので、表の外の収入も 0.0.69 と同じ。

### そのほか
- 勲章: 洋上作戦章 (目標のある作戦海域を海の上で 1 / 10 / 30 回攻略)・演習場章 (1 / 20 / 100 勝)・分離章 (1 / 10 / 30 回)・合流章 (1 / 10 回)。勲章の総数は減っていない。
- 今の外洋の画面の 制海章・友軍連携章・史実再現章 は、輪の制海権・友軍の巡回・史実の海戦が 0.0.72〜0.0.76 (B1・C1・D) で海の上に戻るまで、新しくは取れない (取った勲章は残る)。寄港章・資源輸送章・要塞攻略章・外洋航海章・遠洋章は海の上で数える。
- 保存: 停泊している艦隊の燃料 (`openSea.anchors[].fuel`) を足した。欠けていれば満タンで読む。
