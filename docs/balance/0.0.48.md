# バランス確認 — 0.0.48-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。資源の表は `npm run balance` の出力。

## 装備の強さ

- 共通の装備 8 種の効果は 0.0.47 と同じ。今までは研究すれば何個でも付けられたので、序盤から全艦が 2〜4 枠を埋めていた。0.0.48 は 1 個ずつ作るので、序盤は旗艦から順に埋まる。
- 旧セーブは、研究済みの装備を 1 個ずつ持ち、付けていた分はそのまま残る (外すと倉庫に戻る)。
- 国ごとの装備は、同じ枠の共通の装備より 1.5〜2 倍強い (例: 魚雷改良 ×1.15 → 酸素魚雷 ×1.30、対空機銃 ×1.4 → VT 信管 ×1.6)。そのかわり研究が 1〜3 段深い。
- 敵から回収する部品は、共通の装備より少し弱い〜同じくらい (例: 大口径砲の照準装置 = 砲火力 ×1.08・装填 ×0.95)。研究なしで付けられるのが利点。

## 戦闘の模擬

育成済みの艦隊 (`--grown 1`)、各国・各戦域の最初・中ほど・最後の海域を 2 回ずつ (89 か所)。消耗品は両軍が使い、プレイヤーの艦は研究で開いた分を持つ。

|---|---|---|
| 勝率 | 94% | **95%** |
| 日本 / 米国 / ドイツ / 英国 | 95 / 100 / 91 / 100% | 100 / 96 / 100 / 100% |
| フランス / ソ連 / イタリア | 100 / 86 / 86% | 100 / 86 / **77**% |
| S の割合 | 17% | 26% |
| 戦闘時間の中央値 (最長) | 16 秒 (52 秒) | 15 秒 (900 秒) |

| 推奨階級 | 海域 | 勝率 | 敵 / 自 |
|---|---|---|---|

| 准佐〜少佐 | 5 | 90% | 0.65 |

| 准将〜少将 | 16 | 97% | 2.00 |

- 全体の勝率はほぼ同じで、S の割合が増えた (17% → 26%)。応急修理で耐久が戻り、「残り耐久 85%」の条件を満たしやすくなった。
- 最初の模擬で、自軍の艦が見つかる前から「機関全開」を使い、陣形を崩して突っ込んでいた。AI は「大破寸前で敵が近い時」だけ使うように直した。
- ソ連の北極海 4 (ar4、砲台の海域) は 0% → 50%。島の砲台が国ごとの地上兵器になり、支援の陣地 (高射砲・レーダー・魚雷艇) が砲台より弱いため。ただし 1 回は 900 秒の時間切れ (霧の中で残りの陣地が見つからない)。

## 資源の使い道

- 中盤の 1 時間の余り (燃 1,167・弾 1,338・鋼 2,193・ボ 487、下の表) で、装備なら 4〜6 個作れる。艦隊 6 隻 × 2〜3 枠を埋めるのに 3〜4 時間。
- 艦載機の第 2 世代 (ボ 800) は中盤の余りのボーキの 1.6 時間分、第 3 世代 (ボ 1,200〜2,400) は終盤の 1.4〜2.8 時間分。
- 自国の超兵器 (鋼 3,000〜3,830) は終盤の鋼材の余り (3,186) のほぼ 1 時間分。設計図 5 枚は超兵器海域で 3 回勝てばそろう。
- 解体は建造費より少なく戻る (駆逐艦は鋼 170 → 70)。建てて壊すと損なので、資源を増やす手段にはならない。改造済みの艦は改造費の 30% も戻る。

- 装備改修 (★1〜10)、主砲・魚雷の型の載せ替え (#55 の第 3・4 段階)、機雷原・防潜網・特殊潜航艇の基地 (#251)、他国の艦の設計図 (#150) は残り (追跡 issue に書く)。
