# バランス確認 — 0.0.37-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。表は `npm run balance` の出力。
この版で変えたのは、修理の最短時間・突入と撃沈の制限時間・初期艦・陸上目標の数え方・専用改装の艦の改三の方向。資源の収支・建造の時間・育成の速さ・報酬は 0.0.36 から変えていない。

## 修理の時間 (#275)
- 耐久 75% 以上は、今どおり「即時修理」(待ち時間なし、資源は払う)。ボタンと時間の欄に「即時」と出すようにした。
- 75% 未満は、最短 30 秒にした。前は駆逐艦の 74% が約 4 秒 (入渠半額の時は約 2 秒) で、すぐ終わったように見えた。
- 大破の戦艦が 3〜4 分かかるのは変わらない。

## 陸上目標の数え方 (#278)
- 「撃沈」「6 隻以上の艦隊に S」は艦だけで数える。陸上目標は「陸 n / m」として別に出す。
- 報酬・経験値・戦功は、今どおり陸上目標も数える (陸上目標の多い海域で報酬が減らないように)。
- 魚雷と爆雷は陸上目標を狙わない。

## 専用改装の艦の改三の方向 (#277)
- 大和・長門など 18 隻も、改三の方向を選べるようにした。
- 方向が弱める能力は、専用改装から差し引く。強める能力は、専用改装と方向の強い方をとる (重ねない)。大和の対空改装に「対空」の方向を重ねると上限を超えるため。
- 全艦・全方向で、強化の上限 (`ProgressionBalance.test.ts`) に収まることを確かめた。
