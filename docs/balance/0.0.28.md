# バランス確認 — 0.0.28-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。表は `npm run balance` の出力 (日本艦・この版のコード)。
1 時間の想定 (出撃回数・被害・研究・改造・施設) は `src/data/economy.json`、目安は `tests/unit/Economy.test.ts`。

## 目安と結果

- どの時期も、どの資源も「1 時間の収入 ≥ 支出の 8 割」(建造を除く) → 満たす (最小は終盤の燃料 1.26 倍)。
- 鋼材は 1 時間で、その時期の艦が 1 隻以上建造できるだけ貯まる → 序盤 12.6 隻 (吹雪)・中盤 3.4 隻 (高雄)・終盤 2.0 隻 (長門)。
- 鋼材が建造を止める資源にならない (燃料・弾薬で建造できる隻数の半分以上) → 満たす。
  - 0.0.27 の値では、序盤の鋼材が燃料の 0.46 倍で、これを満たさなかった。「鋼材が足りない」と感じた原因。
- 終盤は燃料が一番先に尽きる (長門 1.1 隻分)。次の版でも見る。
