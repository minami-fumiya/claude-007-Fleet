# バランス確認 — 0.0.31-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。表は `npm run balance` の出力。

## 任務 (#180)

- 表示を各 10 件に (毎時 3・デイリー 8・ウィークリー 6 から)。種類は毎時 30・デイリー 31・ウィークリー 25。
- 経済モデルに「達成率」を入れた (`economy.json` の `questCompletion`: 毎時 0.6・デイリー 0.7・ウィークリー 0.6)。戦域・船団・訓練など、その時に達成できない任務が混ざるため。
- 調整した値:
  - 毎時の燃料・弾薬を 1.15 倍 (10 件すべてで 1 時間あたり燃料 約 590・弾薬 約 570。目安 600)。
  - デイリーに高速修理材・高速建造材の付く任務を 5 つ追加 (1 日平均 約 3.5 個。目安 3〜4)。
- 結果: 任務の収入は 785 → 1,022 (燃料 / 時)。戦闘の収入に対して 燃料 0.41〜0.45・弾薬 0.45〜0.49 (目安 0.3〜0.5、Economy.test で固定)。
- 終盤の燃料 (0.0.30 で課題): 長門の建造 1.1 → 1.3 隻 / 時。差し引き 燃料 +1,120 / 時。

## 掃討 (#181)

- 1 日 3 回 → 最大 3 回・1 時間に 1 回回復。毎日遊ぶ人は回数が増え、海域を複数持つ中盤以降の収入が上がる。
- 経済モデルの掃討は 1 時間あたり 中盤 1 回・終盤 2 回のまま (回復の上限 = 海域ごとに 1 回 / 時なので、2 海域を回せば届く)。掃討は戦闘の 8 割の報酬なので、戦闘より割がよくはならない。

## 戦績 (#177)・お知らせ (#192)

- 史実シナリオの戦闘は戦績の通算に入れない (無料で何度でも戦えるため、撃沈数の勲章を稼げないように)。史実は専用の勲章 (戦史章・両陣営章・史実従軍章) で数える。
- お知らせは表示だけで、値は変えていない。

## そのほか (0.0.30 から変更なし)

- 艦の強さ・作戦の難しさ・建造と入渠の時間・育成と昇進の速さは変えていない (Balance / ProgressionBalance / EarlyGameLoop のテストは 0.0.30 と同じ目安で通る)。
