# バランス確認 — 0.0.57-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。資源の表は `npm run balance` の出力、模擬は `npm run sim -- --sample 1 --runs 3`。
この版は「戦闘の隊形と AUTO」(#400 #404 #368)。

## 確かめたこと

- **米国の北極海 4 (ar4、准将、砲撃):** 育てていない艦隊 (`--grown` なし) では 0.0.56 も 0.0.57 も 25〜33%。負けはどれも開始 14〜20 秒で旗艦が沈む形で、旗艦の受けた損害を記録すると、霧の中で距離 300〜480 から砲台 (38cm)・飛行場・ドイッチュラントに 4 秒ほどで撃たれていた (アイオワ 750 → 0)。推奨階級まで育てた艦隊 (0.0.52 までの模擬と同じ条件) では 100% (2 S・1 B)。#368 の「0〜25%」は育てていない艦隊での数字だった。地上の目標を射程いっぱいから撃つ形も試したが、育てていない艦隊が丸ごと沈んで悪くなったので戻した。
- **北極海 1 (ar1):** 一度 0% と出たが、模擬の途中で依存の入れ替えをした影響だった。流し直すと 0.0.56 のコードでも 0.0.57 のコードでも 100% (6 戦ずつ)。
- **支援艦隊の隊形:** E2E で、演習の支援艦隊 (3 隻) が 8 秒たっても旗艦から 600 以内にまとまっていることを確かめた。
- **演習の敵:** 演習は報酬が演習の分だけで、敵が増えても資源の収支は変わらない。勝ち負けの重さも同じ数どうしになる。
- **資源の表:** 0.0.56 と同じ。
- **勲章:** 「総力演習章」(3 艦隊以上どうしの演習で 1 / 5 / 20 回勝利) を足した。
