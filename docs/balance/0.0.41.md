版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。資源の表は `npm run balance`、戦闘の表は `npm run sim` (#320) の出力。
この版は、戦域の解放と難しさ (#293)・作戦の時間 (#307)・戦闘の模擬 (#320)・時短アイテムと経済 (#321)。艦の強さ・建造と入渠の時間・熟練度・任務は 0.0.40 から変えていない。

## 戦闘の模擬 (#320)

推奨階級の艦隊 (その階級の艦枠ぶん、建造できる最強の艦。旗艦は空母以外、空母は 3 分の 1 まで。改修・研究・艦長なし) で、各国・各戦域の最初・中ほど・最後の海域を 2 回ずつ (96 か所)、AUTO で戦った。前哨戦は含まない。

| | 0.0.40 の戦闘 + #293 | 艦と砲弾 1.25 倍 (試した版) | 0.0.41 |
|---|---|---|---|
| 勝率 (全体) | 39% | 22% | **49%** |
| 敵を強くしない戦域 | 48% | 29% | 56% |
| 遠い戦域 (敵 1.5〜2.3 倍) | 29% | 20% | 42% |
| 戦闘時間 (中央値) | 16 秒 | 7 秒 | 20 秒 |
| 勝った戦闘の時間 (平均) | 19 秒 | 19 秒 | 24 秒 |
| 勝った戦闘の評価 S / A / B / C | — | — | 16 / 36 / 34 / 15% |

- **わかったこと:**
  - 負けの多くは旗艦の喪失。敵は旗艦を狙い、AUTO の旗艦は射程の 4 分の 3 まで寄る。残りの艦の 6〜8 割が残ったまま負ける。
  - 空母のいる敵の雷撃機が、開始 4〜5 秒で旗艦を沈めていた → 最初の攻撃隊を 20 秒後にした。航空攻撃の集中は #328。
  - 旗艦が火災・浸水で沈むと、同じフレームで戦闘が止まる不具合があった → 直した。
- 模擬の艦隊は改修・研究・艦長が無く、AUTO なので、実際のプレイヤーより弱い。勝率 5 割は「推奨階級の素の艦隊で五分」の目安。
- 戦闘時間は AUTO で 20 秒ほど。手動で戦うプレイヤーは数倍かかる。経済モデルの 1 時間の戦闘数は変えていない。
- 全国・全海域の表は、下の「戦闘の表」。
