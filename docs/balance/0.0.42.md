## 入手と解禁 (#285)

- 報酬艦: 各国の各戦域に 3 隻以上 (日本 南太平洋 4・地中海 3・北太平洋 3・インド洋 3 …)。追加は、級の 2 番艦以降から、海域の上限の艦種 (`rewardShip`) 以下で、深さに合う格を選んだ。級の 1 番艦は建造できるまま。
- ドイツのインド洋は駆逐艦 3 隻になった (ドイツに大きな艦の姉妹が少ない)。次の版で見直す。
- 艦長: 1 国 30 人。S 勝利の 3% (1 時間 6 戦・S 3 割で 1 時間 0.05 人)、深さ 3 以上の初 S (国ごとに約 25 海域)、少佐以上の昇進 (8 回)。全員そろうまでの目安は 40〜60 時間 (任務の分を含む)。

## 戦闘の模擬 (#320)

推奨階級の艦隊 (改修・研究・艦長なし、AUTO) で、各国・各戦域の最初・中ほど・最後の海域を 2 回ずつ戦った (96 か所のうち 94 か所。時間切れで 2 か所が欠けた)。

| | 0.0.41 | 0.0.42 (中分類の補正を敵にも) | 0.0.42 |
|---|---|---|---|
| 勝率 (同じ 94 か所) | 49% | 22% | **44%** |
| 日本 / 米国 / ドイツ / 英国 | 67 / 53 / 36 / 47% | 29 / 40 / 11 / 23% | 46 / 70 / 33 / 50% |
| フランス / ソ連 / イタリア | 42 / 50 / 60% | 21 / 8 / 21% | 38 / 17 / 50% |
| 遠い戦域 (敵 / 自 1.2 倍超) | 7% | — | 4% |

- **わかったこと:** 中分類の補正 (防空艦の対空 ×1.5 など) を敵にもかけると、勝率が半分に落ちた (敵の防空巡洋艦が艦載機を落とす)。難しさの曲線は戦力の比で決めていて、この補正を含まない → 補正はプレイヤーの艦だけにした。
- **ソ連 17%:** 30.5cm 砲を戻した分 (#319)。ソ連は 1920 年以降の戦艦が無い。次の版で、ソ連の戦艦の専用改装か計画艦 (#309) で埋める (#331)。
- 日本は 67 → 46%。空母の艦載機 (赤城・加賀 14 → 12) と、2 回ずつの模擬のぶれ。次の模擬で見る。
