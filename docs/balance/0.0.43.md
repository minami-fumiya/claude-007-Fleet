## 士気 (#54)

- 毎回出撃する艦は、勝利で 1 戦 −7、10 分の回復 +3 → 10 分ごとに −4。50 から 30 未満 (疲労) まで約 50 分、5 戦。S 勝利なら −3 + 3 で保つ。
- 疲労の罰は小さい (回避 −3%・装填 8% 遅い)。疲労から 50 までは 100 分。給糧艦 1 つで +30。
- 1 時間遊ぶと、主力の何隻かが疲労する。支援艦隊・遠征・寮舎で艦を入れ替える理由になる (この版の狙い)。

## 動作速度 (#99)

`npm run perf` (`docs/specs/systems/performance.md`)。8 隻 対 10 隻で、戦闘の処理は CPU 1/4 でも 1 フレーム 5.7〜6.6 ms (60 fps の 4 割)。開発用コンテナは GPU が無いので fps は描画で決まり、実機の値ではない。

## 戦闘の模擬 (#320)

推奨階級の艦隊 (改修・研究・艦長なし、AUTO) で、各国・各戦域の最初・中ほど・最後の海域を 2 回ずつ戦った (96 か所すべて)。0.0.43 から、模擬の艦隊は推奨階級のコストの上限内で選ぶ。

| | 0.0.42 | 0.0.43 (コストの上限内) |
|---|---|---|
| 勝率 (0.0.42 と同じ 94 か所) | 44% | **40%** |
| 敵 / 自 の平均 | 1.22 | 1.26 |
| 日本 / 米国 / ドイツ / 英国 | 46 / 70 / 33 / 50% | 50 / 53 / 33 / 37% |
| フランス / ソ連 / イタリア | 38 / 17 / 50% | 42 / 21 / 45% |

| 深さ | 海域 | 0.0.42 勝率 | 0.0.43 勝率 | 敵 / 自 (0.0.42 → 0.0.43) |
|---|---|---|---|---|
| 1〜3 | 27 | 83% | 83% | 0.50 → 0.50 |
| 4〜5 | 19 | 47% | 45% | 0.70 → 0.71 |
| 6〜7 | 19 | 26% | 16% | 1.46 → 1.53 |
| 8〜9 | 29 | 16% | 12% | 2.06 → 2.16 |

- コストの上限で、深さ 5 以上の艦隊の戦力が 3〜5% 下がった。浅い海域は、もともと上限より安い艦で組むので変わらない。
- 勝率は 44 → 40%。2 回ずつの模擬のぶれ (国ごとに ±15%) の内で、深い海域ほど下がる向きは同じ。
- 深さ 6 以上が低いのは前の版と同じ (模擬は改修・研究・艦長・練度なし)。この版で加わった支援艦隊 (少佐から) と友軍艦隊は、模擬に入っていない。深い海域は、支援艦隊を出せる階級 (少佐〜) で挑むものとして置く。
- 中央値の戦闘時間 18 秒、S の割合 5%。ソ連の北極海 4 は 1 回が 900 秒の時間切れ (0.0.42 は 32 秒)。

## 目安から外れた値

- ソ連の勝率 21% (0.0.42 から 17 → 21%)。#331 (ソ連の戦艦) で埋める。
- ソ連の北極海 4 の時間切れ 1 回 → 次の模擬で再現するか見る。再現すれば、決着のつかない組み合わせを issue にする。

- 動作速度: 実機の fps はまだ測れていない (このコンテナは GPU が無い)。動作情報の値の報告を待つ。
