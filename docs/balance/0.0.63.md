## 確かめたこと

### 模擬の不具合 (#433)
- 戦闘の模擬は、ゲームの保存の部品とは別の複製を読み込んでいた。模擬が書いた保存 (階級・研究・熟練度・損傷の消去) がゲームに届かず、同じページの 2 戦目からは前の戦闘の損傷を持ち越していた (1 隻の艦隊は耐久 10〜45% から始まっていた)。
- 0.0.62 のバランス確認の「最初の海域が負けやすい」(#433) は、この不具合によるものが大きかった。直した後、日本の p1 は 5 戦 3 勝 (フレッチャー相手で戦力比 1.02、五分の勝負) で、ほかの国の最初の海域は 100%。
- 0.0.59 の総点検や、それ以前の模擬の表も、2 戦目以降は損傷を持ち越した数字だった。次の総点検 (0.0.69 の後) で全海域を流し直す。
