### 戦域の広さ (海の区画)
南太平洋 821・インド洋 374・北大西洋 257・南大西洋 242・北極海 122・北太平洋 113・地中海 22・バルト海 8・黒海 5。地中海・バルト海・黒海は狭いが、作戦海域を置く広さはある (0.0.69 で 2 × 2 区画の作戦海域を置く時に見直す)。

### 重さ
- 当たり判定のある陸は 3 × 3 区画分だけ (陸の区画 1 つで円 16 個)。広い海に出ても、普通の戦闘より動く物は少ない。
- 早送りは物理の計算を増やさず、艦の速さを上げる。×8 で 1 フレームに進む距離は 20 px ほど (60 fps)。

### 画面
- 縦・横で、広い海の戦闘画面 (海図・速さのボタン・現在地と燃料) と海図の画面の文字が重ならず、はみ出さないことを E2E で確かめた。
- ミニマップは周りの 3 × 3 区画だけ、海図は世界全体 (分けた)。

### そのほか
- 勲章: 大洋航海章 (10 / 100 / 500 区画走る)・海図作成章 (1 か国で 50 / 300 / 1000 区画探索する)。勲章の総数は減っていない。
- 保存: `openSea` (探索済みの区画・走った距離・航海の回数) を国ごとに足した。欠けていれば空で読む。
