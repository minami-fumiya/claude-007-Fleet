# バランス確認 — 0.0.39-alpha (#223)

版を上げる前の全体確認 (CLAUDE.md「版ごとのバランス確認」)。表は `npm run balance` の出力。
この版で変えたのは、資源の収支 (#296)・評価 S〜D (#295)・国の解放 (#294)。艦の強さ・作戦の敵・育成・建造と入渠の時間は 0.0.38 から変えていない。

## 資源の収支 (#296)
プレイテスト第 14 弾で「鋼材が足りず、燃料と弾薬が余る」と報告された。

0.0.38 の見積もりで、1 時間の余りで建造できる隻数を比べた (下の表)。序盤と中盤は、鋼材の隻数が燃料の半分ほどしかなかった。建造の鋼材が「耐久 + 装甲 × 5」で、燃料の 2〜3 倍かかるため。

## 評価 S〜D (#295)

| 評価 | 0.0.38 | 0.0.39 |
|---|---|---|
| S | 喪失なし・残り耐久 60% 以上・600 秒以内 | 喪失なし・残り耐久 85% 以上・大破 (耐久 25% 以下) なし・時間内 |
| S の時間 | 600 秒 | 制限時間の 2/3 (突破 180 → 120 秒、撃沈目標 300 → 200 秒)。制限がない時は 420 秒。遅滞 (時間まで守れば勝ち) は時間を問わない |
| A | 喪失なし | 喪失なし・残り耐久 60% 以上 |
| B | 喪失が半分以下 | 喪失 1 隻まで、または残り耐久 40% 以上 |
| C | それ以外の勝利 | それ以外の勝利 |

- 結果の画面に、S に届かなかった理由を出す。例: 「S まで: 残り耐久 78% (85% 必要)」
- 報酬と戦功の倍率は変えていない (S +20% / +50%)。
- S が取りにくくなる分、掃討の解放 (その海域の初めての S) と S の報酬 (艦長・報酬艦) が遅くなる。
  - 戦闘の流れは見積もりのモデルに無いので、S の取りやすさは数字で確かめられていない。
  - 次の総点検 (0.0.39 の公開後) で、実際に遊んで見直す。
- 勲章「無傷の完勝章」: 喪失なし・残り耐久 95% 以上の勝利。

## 国の解放 (#294)
- ソ連は「少佐への昇進」で開いていた。フランス・イタリアと同じく、その国が戦う戦域の攻略で開くようにした。
- 対象の戦域は、バルト海・北極海・北太平洋のどれか。最初の 4 か国のどれからでも、少なくとも 1 つに行ける。
- 国の選択画面に、進み具合を出す。例: 「いま 北極海 2 / 9」
